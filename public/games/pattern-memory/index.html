이 게임의 핵심

패턴 기억은 잠깐 표시되는 활성 칸을 기억한 뒤 같은 위치를 다시 선택하는 시각 기억 퍼즐입니다. 이번 버전은 한 번 맞히고 끝나는 방식이 아니라 라운드가 계속 이어지는 기록형 게임입니다.

쉬움4×4 · 목숨 3
보통5×5 · 목숨 2
어려움6×6 · 목숨 1

난이도와 라운드 변화

쉬움은 4×4, 보통은 5×5, 어려움은 6×6 보드를 사용합니다. 라운드가 두 번 올라갈 때마다 기억해야 할 칸이 하나씩 늘어나며, 동시에 패턴 표시 시간도 점점 짧아집니다.

  • 쉬움은 충분한 표시 시간과 목숨 3개로 위치 묶기를 연습하기 좋습니다.
  • 보통은 5×5 공간에서 구역별 기억이 중요합니다.
  • 어려움은 6×6, 목숨 1개라 첫 복원의 정확도가 중요합니다.

게임 방법

  1. 난이도를 고르고 시작을 누릅니다.
  2. 파란색으로 표시되는 목표 칸의 위치와 전체 모양을 기억합니다.
  3. 패턴이 사라지면 기억한 칸을 선택합니다. 같은 칸을 다시 누르면 선택을 취소할 수 있습니다.
  4. 필요한 칸 수를 모두 선택한 뒤 선택 확인을 누릅니다.
  5. 정답이면 다음 라운드로 넘어가고, 오답이면 복기 화면이 표시됩니다.

조작과 오답 복기

  • 마우스·터치: 칸을 눌러 선택/해제합니다.
  • 키보드: 방향키로 칸을 이동하고 Enter 또는 Space로 선택합니다.
  • H: 현재 패턴 다시 보기. 점수가 일부 차감되고 완벽 연속 기록이 끊깁니다.
  • N: 새 도전을 시작합니다.
  • 오답 복기에서 초록은 맞힌 칸, 파랑은 빠뜨린 정답 칸, 빨강은 잘못 고른 칸입니다.

목숨이 남아 있으면 복기 후 같은 라운드의 같은 패턴을 다시 보여 줍니다. 탭을 벗어나는 동안 패턴 표시가 진행되지 않으며, 돌아오면 해당 패턴을 처음부터 다시 보여 줍니다.

저장과 기록

진행 중인 라운드, 정답 패턴, 목숨, 점수, 정확도 관련 값은 현재 브라우저에 저장됩니다. 새로고침하면 선택 중이던 입력을 그대로 추측해서 이어가는 대신 현재 패턴을 다시 보여 준 뒤 안전하게 재개합니다.

  • 난이도별 도전 횟수
  • 최고 라운드
  • 최고 점수
  • 최고 정확도
  • 실수 없이 이어 간 최고 완벽 연속 라운드

공략 팁

  • 칸을 하나씩 번호로 외우기보다 왼쪽 위·오른쪽 위·아래처럼 구역으로 나눕니다.
  • 모서리와 중앙처럼 눈에 띄는 기준점을 먼저 기억합니다.
  • 활성 칸을 선, 계단, L자, 덩어리처럼 하나의 모양으로 묶습니다.
  • 입력할 때는 확실한 칸부터 고르고 마지막 한두 칸은 전체 모양을 다시 떠올립니다.
  • 패턴 다시 보기는 기록 경쟁용이라기보다 막히는 라운드의 기억 방식을 분석할 때 쓰는 편이 좋습니다.

자주 묻는 질문

패턴은 매 라운드 새로 나오나요?

네. 각 라운드마다 현재 난이도와 목표 칸 수에 맞춰 새 패턴을 생성합니다.

틀리면 바로 끝나나요?

어려움은 목숨이 1개라 끝나지만 쉬움과 보통은 남은 목숨이 있으면 같은 패턴을 다시 보고 재도전합니다.

선택을 잘못 눌렀으면 어떻게 하나요?

확인 전에는 같은 칸을 다시 눌러 선택을 취소할 수 있습니다.

새로고침하면 진행이 사라지나요?

진행 상태를 현재 브라우저에 저장하며, 복구 시 현재 패턴을 다시 보여 주고 이어갑니다.

모바일에서도 가능한가요?

네. 터치 선택을 지원하며 작은 화면에서도 보드가 화면 폭에 맞춰 줄어듭니다.
