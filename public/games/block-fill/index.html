이 게임의 핵심

블록 채우기는 5×5 또는 6×6 보드에 여러 폴리오미노 조각을 넣어 장애물을 제외한 목표 칸을 모두 메우는 공간 퍼즐입니다. 각 스테이지는 실제 정답 배치에서 조각을 추출해 만들었기 때문에 풀 수 없는 판이 생성되지 않습니다.

스테이지5단계 캠페인
장애물폭탄칸·금지칸은 채우지 않음
보조 기능회전·되돌리기·힌트·자동 저장

게임 방법

  • 대기 조각을 선택한 뒤 보드의 기준 칸을 눌러 배치합니다.
  • 조각은 90도 단위로 회전할 수 있습니다.
  • 다른 조각, 폭탄칸, 금지칸과 겹치거나 보드 밖으로 나가면 놓을 수 없습니다.
  • 모든 조각을 사용해 목표 칸을 정확히 채우면 다음 스테이지가 열립니다.

조작과 진행

  • 회전: 선택한 조각을 90도 돌립니다. 키보드 R도 사용할 수 있습니다.
  • 되돌리기: 직전 배치를 되돌립니다. 키보드 U를 지원합니다.
  • 힌트: 아직 놓지 않은 조각 하나의 정답 위치를 잠시 표시합니다. 키보드 H를 지원합니다.
  • 조각을 이미 놓은 뒤 다시 선택하면 다른 위치로 옮길 수 있습니다.

기록과 저장

진행 중인 스테이지, 조각 위치, 회전 상태, 행동 수와 경과 시간은 현재 브라우저에 자동 저장됩니다. 다른 탭에 있는 동안에는 기록 시간이 늘어나지 않습니다.

  • 스테이지별 최단 시간과 최소 행동을 기록합니다.
  • 힌트를 사용한 완주는 캠페인 진행에는 반영되지만 최단 시간·최소 행동 기록 갱신에서는 제외됩니다.
  • 브라우저 데이터를 삭제하면 저장된 진행과 기록도 사라질 수 있습니다.

공략 팁

  • 면적이 큰 조각과 모서리가 많은 조각부터 후보 위치를 좁힙니다.
  • 폭탄·금지칸 주변에는 들어갈 수 있는 조각 방향이 제한되므로 먼저 확인합니다.
  • 한 칸짜리 고립 공간이 생겼다면 직전 조각보다 그 앞의 큰 조각 배치를 의심합니다.
  • 회전 가능한 모양은 현재 빈칸의 긴 변과 먼저 맞춰 봅니다.
  • 되돌리기를 여러 번 쓰기보다 남은 조각의 면적과 빈칸 모양을 비교한 뒤 다음 수를 정합니다.

모바일 플레이

모바일에서는 조각을 한 번 눌러 선택한 뒤 원하는 칸을 탭하는 방식이 가장 안정적입니다. 조각을 보드 쪽으로 끌어 놓는 드래그 입력도 지원하며, 화면 아래 회전·되돌리기·힌트 버튼은 작은 화면에서 고정형으로 표시됩니다.

자주 묻는 질문

각 스테이지는 정말 풀 수 있나요?

네. 목표 보드를 먼저 정답 조각으로 나눈 뒤 그 조각을 플레이용으로 제공하므로 모든 스테이지에 최소 한 개의 완성 배치가 있습니다.

폭탄칸도 채워야 하나요?

아니요. 폭탄칸과 금지칸은 장애물이라 비워 둔 채 나머지 목표 칸만 채우면 됩니다.

조각을 잘못 놓으면 처음부터 해야 하나요?

아니요. 되돌리기를 사용하거나 놓은 조각을 다시 선택해 옮길 수 있습니다.

힌트는 정답을 자동으로 놓나요?

아니요. 조각 하나의 정답 위치를 잠시 표시할 뿐 실제 배치는 직접 해야 합니다.

새로고침해도 이어지나요?

현재 브라우저의 로컬 저장소를 사용할 수 있다면 진행 중 스테이지를 자동으로 복원합니다.
