무작위 위치에 나타나는 빨간 타깃을 빠르고 정확하게 눌러 목표당 반응시간과 정확도를 측정합니다. 별도 제한시간은 없으며 선택한 난이도의 타깃을 모두 맞히면 한 번의 훈련이 끝납니다.

에임 트레이너 플레이

큰 화면

게임을 불러오는 중입니다.

난이도별 타깃 수와 크기

  • 쉬움: 지름 64px의 큰 타깃 15개
  • 보통: 지름 50px의 타깃 20개
  • 어려움: 지름 38px의 작은 타깃 30개

타깃을 맞히면 즉시 다른 무작위 위치에 다음 타깃이 나타납니다. 난이도별 기록은 따로 관리되므로 같은 난이도끼리 비교하는 것이 좋습니다.

평균 반응시간과 현재 최고 기록

각 타깃이 나타난 시점부터 실제로 눌린 순간까지를 밀리초(ms)로 측정합니다. HUD의 평균은 현재까지 성공한 타깃의 반응시간 평균이고, ‘최고’는 현재 훈련에서 가장 빠른 단일 타깃 기록입니다.

완료 후에는 난이도별 최저 평균 반응시간, 최고 정확도, 최단 총합 시간이 브라우저에 저장됩니다. 단일 타깃 최고와 완료 기록은 서로 다른 지표입니다.

미스와 정확도 계산

빈 공간을 누르면 미스가 1회 늘어나지만 현재 타깃은 그대로 남습니다. 정확도는 성공 횟수를 성공과 미스를 합친 전체 입력 수로 나눈 뒤 백분율로 표시합니다.

미스가 난 뒤에도 같은 타깃의 반응시간 측정은 계속되므로, 빈 공간 클릭은 정확도뿐 아니라 해당 타깃의 기록에도 불리할 수 있습니다.

탭 이동과 새로고침

진행 중 다른 탭으로 이동하면 현재 측정은 중단되고 타깃이 제거됩니다. 돌아온 뒤 중간부터 이어서 측정하지 않으며 새 훈련을 시작해야 합니다. 새로고침도 진행 중 타깃·현재 반응시간 목록을 복원하지 않습니다.

기록을 안정적으로 비교하는 방법

  • 타깃 가장자리보다 중심을 목표로 잡아 작은 타깃에서 미스를 줄이세요.
  • 현재 포인터 위치에서 다음 타깃 중심까지 바로 이동해 불필요한 중앙 복귀를 줄이세요.
  • 마우스와 터치는 입력 방식과 화면 크기가 다르므로 같은 기기·같은 입력 방식끼리 기록을 비교하세요.
  • 한 번의 가장 빠른 반응보다 평균 반응시간과 정확도를 함께 확인하세요.
