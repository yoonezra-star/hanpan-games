이 게임의 핵심

스도쿠 클래식은 9x9 보드의 각 행, 열, 3x3 박스에 1부터 9를 한 번씩 배치하는 논리 퍼즐입니다. 쉬움·보통·어려움의 고유 해답 퍼즐을 매 판 안전하게 변형해 반복 플레이할 수 있습니다.

정식 규칙을 유지하면서도 브라우저에서 편하게 풀 수 있도록 숫자 패드, 후보 메모, 선택 구역 강조, 오류 표시 선택, 되돌리기와 자동 저장을 한 화면에 모았습니다. 힌트 없이 완성한 시간은 난이도별 최고 기록으로 남습니다.

핵심 목표모든 빈칸을 채워 각 행·열·3x3 박스에 1부터 9를 완성합니다.
난이도쉬움·보통·어려움의 세 단계에서 서로 다른 단서 구조를 풉니다.
실력 포인트후보 줄이기, 숨은 싱글 찾기, 박스와 행·열 교차 확인입니다.
편의 기능후보 메모, 50회 되돌리기, 자동 저장, 오류 검사와 힌트 3회를 지원합니다.

플레이 포인트

스도쿠 클래식은 9x9 보드의 행, 열, 3x3 박스를 함께 읽는 논리 퍼즐입니다. 후보 메모를 남기고 숫자가 들어갈 수 있는 위치를 교차해 보면 추측 없이도 확정 칸을 찾을 수 있습니다.

추천 상황정식 9x9 규칙과 단계별 난이도로 차분하게 추론하고 싶을 때
좋은 기록힌트 없이 빠르고 정확하게 9x9 보드 완성
주의할 점한 행만 보고 같은 3x3 박스와 열의 후보를 놓치는 실수
  • 빈칸이 적은 행과 3x3 박스부터 확인합니다.
  • 후보가 둘 이상이면 메모 모드로 남겨 둡니다.
  • 같은 숫자가 들어갈 수 있는 위치가 하나뿐인 구역을 찾습니다.

게임 방법

9x9 보드의 빈칸을 채워 각 행, 열, 3x3 박스에 1부터 9가 한 번씩 들어가게 만드는 클래식 논리 퍼즐입니다. 세 난이도와 후보 메모를 지원합니다.

스도쿠 클래식은 별도 앱 설치나 로그인이 필요 없는 무료 웹게임입니다. 페이지 오른쪽 또는 아래쪽 플레이 영역에서 바로 실행할 수 있고, 결과와 최고 기록은 가능한 경우 현재 브라우저 안에만 저장됩니다.

조작과 진행

  • 칸을 누른 뒤 숫자 패드 또는 키보드 1~9로 값을 입력합니다.
  • 메모 모드를 켜면 한 칸에 여러 후보 숫자를 표시할 수 있고 같은 후보를 다시 입력하면 삭제됩니다.
  • 방향키는 선택 칸을 이동하며 Backspace·Delete·0은 사용자 입력과 메모를 지웁니다.
  • 검사 버튼은 오류 자동 표시를 꺼 둔 경우에도 현재 잘못된 숫자를 찾아 표시합니다.

승리와 점수 기준

  • 모든 칸이 고유 해답과 일치하면 자동으로 완성 처리됩니다.
  • 힌트를 사용하지 않은 완성 시간만 현재 브라우저의 난이도별 최고 기록으로 저장됩니다.
  • 입력과 메모, 힌트, 시간은 자동 저장되어 같은 브라우저에서 페이지를 다시 열어 이어갈 수 있습니다.

초보 공략

  • 빈칸이 적은 행, 열 또는 3x3 박스부터 빠진 숫자를 확인합니다.
  • 후보가 하나뿐인 칸은 바로 채우고 둘 이상이면 메모로 남겨 둡니다.
  • 숫자 하나를 채운 뒤 같은 행·열·박스의 메모가 줄어드는지 다시 살펴봅니다.

한 단계 더 올리는 전략

  • 한 박스에서 특정 숫자가 들어갈 수 있는 위치가 한 칸뿐인 숨은 싱글을 찾습니다.
  • 같은 두 후보만 공유하는 두 칸이 보이면 해당 구역의 다른 칸에서 그 후보를 제외할 수 있습니다.
  • 박스 안 후보가 특정 행이나 열에만 모이면 같은 행·열의 다른 박스 후보를 줄일 수 있습니다.

모바일 플레이 팁

  • 9x9 보드는 세로 화면 폭을 채우고 숫자 패드는 바로 아래 한 줄에 고정되어 손가락 이동을 줄입니다.
  • 작은 칸을 오래 누르기보다 칸을 한 번 선택한 뒤 큰 숫자 패드를 사용하면 오입력이 줄어듭니다.
  • 가로 화면이나 전체화면에서는 게임판 크기가 화면 높이에 맞춰져 설명 영역 없이 풀이에 집중할 수 있습니다.

자주 나오는 실수

  • 행의 빠진 숫자만 보고 같은 3x3 박스에서 이미 사용된 값을 놓치는 실수
  • 후보를 확정 숫자처럼 입력해 이후 여러 칸의 판단을 함께 어긋나게 만드는 실수
  • 힌트로 채운 숫자의 근거를 확인하지 않고 다음 칸으로 넘어가는 실수

자주 묻는 질문

퍼즐마다 해답이 하나인가요?

네. 각 난이도는 고유 해답이 검증된 퍼즐을 사용하고 행·열·숫자 치환으로 규칙과 난이도를 유지하며 변형합니다.

메모는 어떻게 입력하나요?

메모 모드를 켠 뒤 숫자 패드나 키보드로 후보를 입력합니다. 같은 숫자를 다시 누르면 해당 후보가 삭제됩니다.

오류 표시를 끌 수 있나요?

네. 오류 표시를 끄면 입력 중 정답 여부를 숨길 수 있고 필요할 때 검사 버튼으로 확인할 수 있습니다.

새로고침하면 풀이가 사라지나요?

아니요. 보드, 메모, 시간, 실수와 힌트 상태를 현재 브라우저에 자동 저장합니다.

힌트를 써도 최고 기록이 되나요?

힌트로 완성할 수는 있지만 공정한 비교를 위해 해당 판은 난이도별 최고 시간에서 제외됩니다.
