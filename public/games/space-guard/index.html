게임을 불러오는 중입니다.

난이도마다 목숨·적 속도·자동 연사가 다릅니다

쉬움목숨 4 · 적 배율 0.72 · 자동 연사 약 420ms
보통목숨 3 · 적 배율 0.90 · 자동 연사 약 500ms
어려움목숨 2 · 적 배율 1.12 · 자동 연사 약 570ms

어려움으로 갈수록 실수 허용 횟수가 줄고 적이 더 빨리 내려오며 자동 발사 간격도 길어집니다. 시간 제한은 없고 목숨이 0이 될 때까지 계속 진행합니다.

적은 8개 기본 열에서 등장합니다

새 적은 화면 위쪽의 8개 기본 x 위치 중 하나에서 등장하고 내려오면서 좌우로 조금 흔들립니다. 적 생성 간격은 max(250ms, 760 - 웨이브×38ms) 구조라 웨이브가 높아질수록 짧아지며 14웨이브부터는 약 250ms 하한에 도달합니다.

10기 격추마다 웨이브가 1 올라갑니다

격추 수가 10·20·30처럼 10의 배수가 될 때 다음 웨이브로 올라갑니다. 적 한 기를 격추하면 20 + 현재 웨이브×5점을 얻습니다. 10번째 적까지는 1웨이브 점수인 25점으로 계산된 뒤 2웨이브가 시작됩니다.

4웨이브부터 새 적의 약 22%가 체력 2의 강화 적으로 등장합니다. 강화 적은 일반 적보다 한 발을 더 맞혀야 제거됩니다.

적을 놓치거나 기체와 충돌하면 목숨을 잃습니다

적이 기체 높이까지 내려온 상태에서 기체와 가로 거리가 가까우면 충돌로 목숨 1개를 잃습니다. 기체를 비켜 지나가더라도 화면 아래쪽을 완전히 통과하면 방어 실패로 역시 목숨 1개가 줄어듭니다.

따라서 피하기만 해서는 생존할 수 없습니다. 화면 가장 아래에 가까운 적을 우선 격추하면서 필요하면 옆으로 피하는 것이 핵심입니다.

자동 연사와 수동 발사는 같은 타이머를 공유합니다

자동 발사는 선택한 난이도의 간격마다 작동합니다. Space 또는 화면의 발사 버튼을 누르면 즉시 추가 탄을 쏘며 자동 연사 누적 시간은 다시 0으로 초기화됩니다. 2026년 8월 27일에는 Space 키를 길게 눌렀을 때 브라우저 키 반복으로 과도하게 발사되지 않도록 반복 입력을 차단했습니다.

키보드·모바일 조작과 일시정지

  • ← / → 또는 A / D: 기체 좌우 이동
  • Space: 수동 추가 발사
  • P 또는 화면 버튼: 일시정지 / 계속
  • 모바일: 왼쪽·오른쪽 이동 버튼과 발사 버튼 사용

일시정지하면 이동 방향 상태가 초기화되고 정지 중에는 이동 버튼도 기체를 움직이지 않습니다. 탭을 벗어나면 자동으로 일시정지되며 돌아온 뒤 직접 계속해야 합니다.

도전 횟수와 최고 기록은 저장 시점이 다릅니다

난이도별 도전 횟수는 방어 시작 순간 1 증가합니다. 최고 점수, 최고 웨이브, 최다 격추는 목숨이 0이 되어 실제 방어가 종료된 판에서만 갱신됩니다.

진행 중 새로고침하면 현재 웨이브·적·점수·목숨은 복구되지 않습니다. 이미 시작 시 저장된 도전 횟수는 남을 수 있습니다.

기록을 높이는 기본 운영

  • 새로 나타난 적보다 방어선에 더 가까운 적을 먼저 확인하세요.
  • 강화 적이 아직 위쪽이라면 아래쪽 일반 적을 먼저 제거할 수 있습니다.
  • 화면 끝에서 끝까지 크게 움직이기보다 중앙 근처에서 위험한 열로 짧게 정렬하세요.
  • 목숨이 적은 어려움에서는 점수보다 방어선 통과를 막는 것을 우선하세요.
