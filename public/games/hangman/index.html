영문 20개와 한글 20개를 번갈아 푸는 행맨

현재 행맨은 영문 알파벳 모드와 한글 초성 모드를 따로 제공합니다. 어휘는 생활, 여행, 자연, 음식, 과학 다섯 카테고리로 나뉘며 각 언어 20개씩 총 40개가 들어 있습니다.

한글ㄱ~ㅎ 초성으로 음절 공개
직접 추리전체 단어 입력도 지원

모드와 난이도

영문 행맨은 키보드 A~Z와 화면 알파벳 버튼을 모두 사용할 수 있습니다. 한글 초성 행맨은 19개 초성 버튼을 사용하며, 같은 초성으로 시작하는 음절이 한 번에 공개됩니다. 한글을 자모 단위로 억지 조합하지 않고 초성 추리에 집중하도록 구성했습니다.

  • 쉬움: 실수 8회, 기본 배점 1배
  • 보통: 실수 6회, 기본 배점 2배
  • 어려움: 실수 5회, 기본 배점 3배
  • 카테고리: 전체·생활·여행·자연·음식·과학

게임 방법

  1. 언어, 난이도, 카테고리를 고르고 새 도전을 누릅니다.
  2. 카테고리와 짧은 뜻 힌트를 읽고 포함될 가능성이 높은 글자를 고릅니다.
  3. 맞힌 글자는 단어 위치에 공개되고, 없는 글자는 실수 1회로 계산됩니다.
  4. 정답을 알았다면 입력창에 전체 단어를 적고 바로 확인할 수 있습니다.
  5. 전체 단어 오답도 실수 1회이며 같은 오답 단어를 다시 입력해도 추가 실수는 붙지 않습니다.
  6. 실수 한도를 다 쓰기 전에 모든 칸을 열거나 전체 단어를 맞히면 승리합니다.

진행 중인 단어, 선택한 글자, 오답 단어, 실수 수, 점수, 연승과 힌트 사용 여부는 현재 브라우저에 자동 저장됩니다. 새로고침해도 진행 중인 단어를 이어갈 수 있습니다.

점수와 기록

맞는 글자를 찾으면 점수가 올라가고 틀린 글자나 전체 단어 오답은 일부 점수를 잃습니다. 단어 완성 시에는 남은 실수 기회가 많을수록 큰 보너스를 받으며, 한 글자 힌트를 쓰지 않았다면 추가 보너스가 붙습니다.

  • 맞는 글자: 난이도 배수에 따라 점수 추가
  • 틀린 글자·전체 단어 오답: 점수 일부 차감
  • 완성 보너스: 남은 실수 기회와 난이도에 따라 증가
  • 힌트 사용: 한 글자를 공개하지만 점수를 차감하고 무힌트 보너스를 잃음
  • 승리 후 다음 단어를 이어가면 현재 세션 점수와 연승 유지
  • 패배·포기 시 연승은 0으로 초기화

기록은 언어와 난이도 조합별로 따로 저장합니다. 도전 횟수, 승리 수, 최고 점수, 최고 연승, 승리 시 가장 많이 남긴 실수 기회를 확인할 수 있습니다.

행맨 공략 핵심

  • 영문은 E, A, I처럼 자주 등장하는 모음과 R, S, T, N 계열을 먼저 확인합니다.
  • 글자 빈도만 보지 말고 공개된 글자의 위치와 단어 길이를 함께 봅니다.
  • 한글 초성 모드는 카테고리와 뜻 힌트를 먼저 읽고 자주 등장할 초성을 두세 개 후보로 줄입니다.
  • 전체 단어가 거의 확정됐을 때만 직접 입력하면 불필요한 실수 1회를 아낄 수 있습니다.
  • 한 글자 힌트는 초반보다 실수 여유가 1~2회 남았을 때 사용하는 편이 효율적입니다.
  • 연승 기록을 노릴 때는 어려운 카테고리를 억지로 고정하기보다 전체 또는 익숙한 카테고리부터 안정적으로 이어갑니다.

모바일과 키보드 조작

모바일에서는 글자 버튼이 자동으로 여러 열에 배치되고, 전체 단어 입력창은 세로 레이아웃으로 바뀝니다. 영문 모드는 PC에서 A~Z 키를 바로 눌러 선택할 수 있으며, 입력창에 포커스가 있을 때는 키보드 입력이 글자 선택으로 가로채지지 않습니다.

기록 도전과 판세 읽기

행맨의 연승은 서로 다른 단어를 연속으로 완성한 횟수입니다. 한 단어의 점수보다 글자 빈도, 카테고리 힌트와 남은 실수 기회를 여러 판에 걸쳐 안정적으로 활용했는지 보여 주는 기록입니다.

  • 1연승 · 자주 쓰는 글자와 뜻 힌트로 첫 단어를 완성합니다.
  • 3연승 · 전체 단어 추리는 후보가 충분히 좁혀진 뒤에만 사용합니다.
  • 5연승 · 난이도별 실수 한도를 지키며 다섯 단어를 이어 풉니다.

현재 기록을 해석하는 기준

남은 칸은 적은데 실수가 빠르게 늘면 공개된 글자의 위치보다 빈도만 따라간 경우가 많습니다. 영문은 모음과 자주 쓰는 자음을 나눠 확인하고, 한글은 카테고리와 뜻에서 단어 후보를 먼저 만든 뒤 필요한 초성을 선택하세요.

자주 묻는 질문

한글 행맨은 자모를 하나씩 조합하나요?

아닙니다. 한글 모드는 초성 선택형입니다. 예를 들어 ㄱ을 고르면 ㄱ으로 시작하는 해당 단어의 음절이 공개됩니다.

정답 단어를 바로 입력할 수 있나요?

네. 영문과 한글 모두 전체 단어 직접 입력을 지원하며 맞으면 즉시 승리합니다.

힌트는 몇 번 쓸 수 있나요?

한 단어에서 한 번 사용할 수 있습니다. 아직 열리지 않은 글자 또는 초성 하나를 공개합니다.

새로고침하면 진행이 사라지나요?

진행 중인 단어는 현재 브라우저의 로컬 저장소에 저장됩니다. 브라우저 데이터를 삭제하거나 다른 기기로 바꾸면 이어지지 않습니다.

점수는 단어마다 초기화되나요?

승리 후 다음 단어를 이어가면 현재 세션 점수와 연승이 유지됩니다. 설정 변경이나 게임 자체를 다시 시작하면 새 세션으로 시작합니다.
