게임을 불러오는 중입니다.

난이도마다 틈·이동 속도·중력이 모두 다릅니다

쉬움기둥 틈 150px · 속도 2.3 · 중력 0.32
보통기둥 틈 125px · 속도 2.8 · 중력 0.36
어려움기둥 틈 105px · 속도 3.25 · 중력 0.40

어려움으로 갈수록 통과 공간이 좁아지고 기둥이 더 빠르게 다가오며 낙하 가속도 커집니다. 별도의 1분 제한은 없고 기둥이나 화면 위·아래 경계에 부딪힐 때까지 계속됩니다.

점프는 상승력을 누적하지 않고 세로 속도를 -6.2로 다시 설정합니다

비행은 화면 좌측의 고정된 가로 위치에서 시작하며 기체 중심은 처음 약 y=220에 있습니다. Space, 캔버스 클릭·터치 또는 점프 버튼을 누를 때마다 현재 세로 속도가 -6.2로 바뀝니다.

빠르게 여러 번 눌러 상승력이 합산되는 구조는 아니지만, 상승 중 다시 입력하면 -6.2가 다시 적용되어 높은 상태가 오래 이어질 수 있습니다. 2026년 8월 27일부터 Space를 길게 눌렀을 때 발생하는 브라우저 자동반복 keydown은 점프로 인정하지 않습니다.

기둥 쌍은 약 1.45초마다 새로 생성됩니다

기둥 생성 주기는 난이도와 관계없이 약 1,450ms입니다. 기둥 폭은 56px이며, 생성된 기둥은 선택 난이도의 속도만큼 왼쪽으로 이동합니다.

어려움에서 생성 자체가 더 잦아지는 것은 아니지만 이동 속도가 빨라 화면 오른쪽에서 기체까지 오는 시간이 짧아집니다. 다음 틈 높이를 더 일찍 읽어야 하는 이유입니다.

기둥을 완전히 지난 뒤에 1점이 올라갑니다

기둥 틈에 들어갔다고 바로 통과로 계산하지 않습니다. 기둥 쌍의 오른쪽 끝이 기체 중심의 가로 위치보다 완전히 왼쪽으로 지나간 순간 해당 기둥이 한 번만 점수 처리되고 통과 +1이 됩니다.

따라서 기둥 후단을 완전히 벗어나기 전까지는 현재 높이를 안정적으로 유지하는 것이 중요합니다.

위·아래 화면 경계도 충돌 조건입니다

기체 중심 y가 약 12px보다 위로 올라가거나 408px보다 아래로 내려가면 게임이 끝납니다. 화면 아래에는 지면이 약 y=420부터 그려지므로 낮은 틈을 따라가다가 입력을 너무 오래 쉬는 것도 위험합니다.

기둥과는 기체 중심 기준 약 13px 반경을 사용해 겹침을 판정합니다. 어려움 105px 틈에서는 화면상 여유보다 실제 통과 여유가 더 좁게 느껴질 수 있습니다.

최고 기록과 누적 통과는 통과 순간 바로 저장합니다

도전 횟수는 비행 시작 순간 1 증가합니다. 기둥을 하나 완전히 통과할 때마다 현재 점수를 기준으로 최고 기록을 비교하고, 누적 통과도 1씩 증가시킨 뒤 즉시 브라우저에 저장합니다.

이전에는 최고·누적 통과를 충돌로 판이 끝난 뒤 저장했기 때문에 진행 중 새로고침이나 다른 게임 이동으로 이미 지나간 기둥이 누적 기록에서 빠질 수 있었습니다. 2026년 8월 27일부터는 실제 통과 순간을 기록 기준으로 사용합니다.

일시정지 후에는 직접 재개해야 합니다

P 또는 화면의 일시정지 버튼으로 비행을 멈출 수 있습니다. 정지 중에는 Space·클릭·터치·점프 버튼이 새 점프를 만들지 않습니다.

브라우저 탭이 숨겨지면 자동으로 일시정지되며 탭으로 돌아왔다고 자동 재개되지 않습니다. 준비가 되었을 때 계속 버튼 또는 P를 눌러 재개합니다. 재개 순간 기준 시간을 다시 잡아 숨겨져 있던 시간 때문에 큰 프레임 이동이 생기지 않도록 했습니다.

새로고침 후 현재 비행은 복원되지 않습니다

현재 기체 높이, 세로 속도, 화면의 기둥 위치와 현재 점수를 이어서 복원하는 인게임 세이브는 없습니다. 새로고침하면 새 판을 시작해야 합니다.

다만 이미 시작한 도전 횟수와 실제로 통과해 저장된 최고·누적 기록, 마지막 난이도 선택은 브라우저에 남습니다.

브라우저에 저장되는 데이터

hanpan-flappy-records-v2에는 난이도별 attempts, best, total이 저장됩니다. hanpan-flappy-prefs-v2에는 마지막 선택 난이도 difficulty가 저장됩니다.

기본 공략

  • 상승 중 연속 입력보다 하강이 시작될 때 짧게 한 번씩 보정하세요.
  • 현재 기둥 진입이 안정되면 시선을 오른쪽 다음 기둥 틈으로 옮기세요.
  • 기둥 중앙을 완벽히 맞히기보다 상하 움직임의 진폭을 작게 유지하세요.
  • 어려움에서는 큰 낙하 뒤 연타 복구보다 작은 높이 수정이 안전합니다.

기록 도전과 판세 읽기

플래피 점프의 통과 수는 기둥 한 쌍을 완전히 지난 횟수입니다. 한 번의 입력 강도는 같으므로, 1개·5개·10개 구간은 기둥 중앙을 향해 입력 간격을 일정하게 조절하는 능력을 보여 줍니다.

  • 1개 · 첫 기둥의 틈 중앙을 통과해 점프와 낙하 리듬을 확인합니다.
  • 5개 · 기둥 직전의 급한 연속 입력 없이 일정한 높이를 유지합니다.
  • 10개 · 난이도별 속도와 틈 크기에 맞춘 입력 간격으로 두 자릿수 기록을 만듭니다.

현재 기록을 해석하는 기준

충돌 위치가 틈 위쪽이면 입력이 너무 늦게 몰렸고, 아래쪽이면 다음 점프를 기다린 시간이 길었던 경우가 많습니다. 기체가 틈 중앙에 도착했을 때가 아니라 기둥 앞에서 현재 상승·하강 방향을 보고 미리 한 번 입력하세요.
