Brain & memory

두뇌·기억 게임

공간 기억, 순서 기억, 단어 추리, 암산처럼 서로 다른 인지 과제를 짧게 반복하는 6개 게임입니다.

6 games

두뇌·기억 게임 바로가기

기억 타일12·16·24칸 보드에서 짝 위치를 기억하고 최소 이동 기록에 도전합니다. 사이먼 게임빛과 소리의 순서를 기억해 점점 길어지는 패턴을 그대로 따라 누릅니다. 패턴 기억4×4~6×6 보드의 위치 패턴을 잠깐 보고 다시 복원합니다. 단어 맞추기카테고리와 단계별 힌트를 이용해 제한 기회 안에 단어를 추리합니다. 행맨영문 알파벳·한글 초성과 전체 단어 추리로 숨은 단어를 완성합니다. 수학 등산사칙연산 문제를 제한시간 안에 풀며 정상까지 올라갑니다.

Selection guide

기억·단어·계산 과제로 나누어 고르기

두뇌 게임이라는 이름 아래에서도 필요한 능력은 서로 다릅니다. 기억 타일은 위치와 짝, 사이먼은 순서, 패턴 기억은 짧게 본 공간 배열, 행맨과 단어 맞추기는 언어 후보 축소, 수학 등산은 제한시간 안의 계산 정확도를 사용합니다.

잘하는 분야의 최고 기록만 반복하기보다 다른 과제를 번갈아 플레이하면 어떤 종류의 정보에서 실수가 생기는지 알기 쉽습니다. 조용히 생각하는 단어 게임, 화면을 잠깐 보고 재현하는 기억 게임, 빠르게 답을 내는 계산 게임 중 현재 집중 상태에 맞는 것을 고르세요.

영문·한글 초성행맨카테고리와 뜻, 공개된 위치를 조합해 단어 후보를 줄입니다. 위치·짝 기억기억 타일칸을 구역과 모양으로 묶어 같은 타일의 위치를 찾습니다. 순서 기억사이먼 게임빛과 소리 순서를 짧은 묶음으로 나누어 재현합니다.

나에게 맞는 게임을 고르는 기준

텍스트 힌트를 읽고 후보를 좁히는 과정이 좋으면 행맨과 단어 맞추기가 맞습니다. 시각 정보를 짧게 저장하는 연습은 기억 타일과 패턴 기억, 순서 자체를 이어 붙이는 연습은 사이먼이 적합합니다. 암산 속도를 확인하려면 수학 등산을 선택하되, 어려운 한 문제에 오래 머무르기보다 정확한 풀이 리듬을 유지하세요.

첫 기록을 만드는 연습 순서

기억 과제는 항목을 하나씩 외우지 말고 중앙·모서리·왼쪽 위처럼 위치를 말로 붙이거나 2~3개 묶음으로 나누세요. 행맨에서는 글자 빈도만 따라가지 말고 단어 길이와 공개 위치, 카테고리를 함께 보고, 한글 초성 모드는 뜻에서 실제 단어 후보를 먼저 만든 뒤 필요한 초성을 선택하는 편이 안정적입니다.

모바일에서 편하게 플레이하기

모바일에서는 기억 단계가 끝나기 전에 화면을 스크롤하지 않도록 게임판을 먼저 화면 안에 맞춥니다. 글자 버튼과 숫자 입력은 최소 44px 터치 영역을 사용하지만 빠르게 연속 누르기보다 선택이 반영됐는지 확인하세요. 집중이 끊겼다면 진행 중 판을 억지로 이어가기보다 같은 난이도에서 새 판으로 비교하는 편이 기록 해석에 낫습니다.

기록을 해석하는 방법

기억 게임은 한 번의 최고 단계뿐 아니라 실수 수와 재시도 횟수를 함께 봅니다. 행맨은 점수보다 연승과 남은 실수 기회, 계산 게임은 정답 수와 오답 수, 콤보를 함께 비교하세요. 서로 다른 난이도의 숫자를 직접 비교하지 말고 같은 조건에서 세 번 이상 플레이한 변화로 판단하는 것이 좋습니다.

시작 전 확인 목록

  • 위치, 순서, 단어, 계산 중 어떤 정보를 다루고 싶은지 정합니다.
  • 기억 항목을 구역이나 2~3개 묶음으로 나눕니다.
  • 언어 게임은 빈도와 함께 길이·위치·카테고리를 봅니다.
  • 빠른 오답보다 잠깐 멈춘 정확한 입력을 우선합니다.
  • 같은 난이도의 실수 수와 평균 도달 단계로 변화를 확인합니다.
공간 기억

위치를 묶어 외우기

기억 타일과 패턴 기억은 칸 하나씩 외우기보다 모서리·중앙·구역·도형으로 묶는 편이 효율적입니다.

순서 기억

짧은 덩어리 만들기
