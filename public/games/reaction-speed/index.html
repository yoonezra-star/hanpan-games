평균·중앙값·일관성

부정출발을 제외한 정상 측정값의 평균과 중앙값을 함께 보여 줍니다. 일관성은 측정값의 표준편차를 ±ms 형태로 표시합니다. 한 번의 매우 빠른 기록보다 중앙값과 일관성까지 함께 보면 현재 반응 성능을 더 안정적으로 비교할 수 있습니다.

부정출발

초록 신호 전에 누르면 부정출발로 기록하지만 해당 회차의 반응시간이나 회차 수에는 포함하지 않습니다. 같은 회차를 다시 준비하므로 평균값이 부정출발 시간으로 왜곡되지 않습니다.

초록 신호 뒤 시간 측정

초록 신호가 나타난 뒤에는 별도의 자동 시간초과가 없습니다. 사용자가 실제로 누르는 순간까지의 시간이 정상 반응값으로 기록됩니다. 탭을 벗어나면 현재 대기 또는 초록 상태만 취소하고 이미 완료한 측정값과 회차는 유지합니다.

조작과 저장

화면을 터치·클릭하거나 Space/Enter를 사용할 수 있습니다. 진행 중인 5회·10회 측정 세트는 새로고침 뒤 복구하지 않으며 모드·소리 설정과 완료 도전에서 갱신한 모드별 최고 단일 기록, 최저 평균·중앙값·일관성을 브라우저에 저장합니다.

공략 팁

  • 손가락이나 엄지를 입력 위치 가까이에 두되 힘을 주지 않아 부정출발을 줄입니다.
  • 한 번의 최고 기록보다 평균·중앙값·일관성을 함께 비교하세요.
  • 정밀 10회는 한 회차의 극단값 영향이 5회 모드보다 상대적으로 작습니다.
  • PC와 모바일은 입력 지연 특성이 다르므로 같은 기기·같은 입력 방식끼리 기록을 비교하세요.

기록 도전과 판세 읽기

반응속도는 한 번의 최고 기록보다 정상 측정값을 여러 번 모은 평균과 중앙값이 더 안정적인 지표입니다. 이번 판 도전은 실제 완료된 측정 개수를 세어 1회, 3회, 기본 5회 세트까지의 진행을 보여 줍니다.

  • 1회 · 초록 신호가 나온 뒤 첫 정상 반응값을 기록합니다.
  • 3회 · 부정출발을 제외한 세 개의 값을 모아 편차를 확인합니다.
  • 5회 · 클래식 또는 스프린트 기본 세트를 끝내 평균과 중앙값을 비교합니다.

현재 기록을 해석하는 기준

최고 기록만 빠르고 중앙값이 느리다면 한 번의 우연한 입력이 전체 체감을 대표하지 못합니다. 평균과 중앙값 차이가 크면 매우 느린 회차가 섞였는지 기록 목록을 보고, 일관성 수치가 크면 손 위치와 시선 위치를 고정한 뒤 다시 측정하세요. 다른 기기의 수치는 입력 지연이 달라 직접 비교하지 않는 편이 좋습니다.

단계별 연습 루틴

첫 세트는 기록을 의식하지 말고 부정출발 없이 다섯 번 완료합니다. 두 번째 세트에서는 손가락을 화면 가까이에 두고 신호 영역 중앙만 바라봅니다. 세 번째 세트에서 평균, 중앙값, 일관성을 비교해 가장 느린 한 회가 집중 문제인지 기기 입력 문제인지 판단하세요.

모바일 조작과 기록 조건

모바일 브라우저에서는 스크롤이나 확대 제스처가 섞이지 않도록 반응 패드 중앙을 한 손가락으로 누르세요. 배터리 절약 모드, 블루투스 입력 장치, 백그라운드 앱 상태가 지연에 영향을 줄 수 있으므로 기록 비교 전에는 같은 기기와 조건을 유지해야 합니다.

FAQ

15초나 1분이 지나면 자동 종료되나요?

아니요. 고정 전체 시간 제한이 아니라 클래식 5회, 정밀 10회, 스프린트 5회의 정상 반응값을 모두 모으면 측정이 끝납니다.

부정출발은 평균에 포함되나요?

아니요. 회차를 소비하지 않고 정상 반응시간 통계에서도 제외됩니다.

초록 신호 뒤 너무 늦게 누르면 자동 실패인가요?

아니요. 별도 자동 시간초과가 없으며 실제 입력 순간까지의 시간이 반응값이 됩니다. 단, 탭을 벗어나면 해당 대기 또는 초록 상태를 취소하고 같은 회차를 다시 준비합니다.

새로고침하면 진행 회차가 복구되나요?

아니요. 진행 중 측정 세트는 복구하지 않고 완료된 최고 기록과 모드·소리 설정만 저장합니다.
