난이도가 올라갈수록 확인할 칸은 늘고 한 개체가 보이는 시간은 짧아집니다. 시작 버튼도 선택한 난이도의 실제 제한시간을 표시합니다.

일반 76%·골든 14%·폭탄 10%

한 번에 한 칸만 활성화됩니다. 무작위 판정상 일반 두더지 🐹는 약 76%, 골든 ⭐은 약 14%, 폭탄 💣은 약 10% 확률로 등장합니다. 확률은 장기적인 생성 비율이며 짧은 한 판에서는 실제 비율이 달라질 수 있습니다.

일반과 골든은 눌러야 하는 목표이고 폭탄은 누르지 않고 사라지게 두는 것이 정답입니다. 폭탄을 그냥 보내면 감점도 없고 콤보도 유지됩니다.

점수와 콤보 계산

일반 또는 골든을 성공적으로 누르면 콤보가 1 증가한 뒤 기본 점수 + min(20, 현재 콤보×2)가 더해집니다. 일반 기본 점수는 10점, 골든은 25점입니다.

현재 활성 칸이 아닌 빈 구멍을 누르면 -2점과 콤보 초기화가 발생합니다. 폭탄을 누르면 -15점과 콤보 초기화가 발생합니다. 점수는 두 경우 모두 0 아래로 내려가지는 않습니다.

한 번 나타난 목표는 한 번만 득점됩니다

성공 목표를 누르면 해당 개체를 즉시 제거한 뒤 약 100ms 후 다음 개체를 생성합니다. 2026년 8월 27일에는 다음 개체가 나오기 전 같은 칸을 연속 클릭해 한 목표를 여러 번 득점할 수 있던 중복 판정 창을 제거했습니다.

놓침과 정확도는 서로 다른 지표입니다

일반·골든 두더지가 제한 노출 시간 안에 눌리지 않으면 점수 감점 없이 콤보만 0으로 초기화됩니다. 놓침 자체는 클릭으로 계산되지 않습니다.

화면의 정확도는 성공한 일반·골든 클릭 ÷ 전체 클릭 × 100입니다. 빈 칸과 폭탄 클릭은 분모에 포함되어 정확도를 낮추지만, 아무것도 누르지 못한 놓침은 정확도를 직접 낮추지 않습니다. 따라서 이 값은 목표 포착률보다 ‘입력 정확도’에 가깝습니다.

도전 횟수와 최고 기록의 갱신 시점

난이도별 도전 횟수는 시작 버튼을 누르는 순간 1 증가합니다. 최고 점수, 최대 콤보, 최고 정확도는 제한시간을 정상 완료한 판에서만 갱신됩니다.

진행 중 다른 탭으로 이동하면 현재 판을 중단하고 타이머와 활성 개체를 정리합니다. 이미 증가한 도전 횟수는 남을 수 있지만 중단 판의 점수·콤보·정확도는 최고 기록에 반영하지 않습니다. 새로고침 후 중간 판을 복구하는 기능도 없습니다.

기록을 안정적으로 높이는 방법

  • 직전 칸을 계속 보지 말고 보드 중앙 부근을 기준 시야로 두세요.
  • 폭탄은 반응하지 않는 것이 정답이므로 모양을 확인한 뒤 한 번만 입력하세요.
  • 빈 칸을 잘못 눌러도 현재 목표가 즉시 사라지지 않으므로 연타 대신 활성 칸을 다시 확인하세요.
  • 최고 점수만 보지 말고 최대 콤보와 입력 정확도를 함께 비교하세요.
  • 모바일과 마우스는 입력 조건이 다르므로 같은 기기·같은 난이도끼리 기록을 비교하세요.
