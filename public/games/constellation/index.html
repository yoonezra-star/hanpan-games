별자리 잇기

흩어진 별을 1번부터 숫자 순서대로 눌러 연결합니다. 고정된 1분 제한은 없으며 각 단계의 모든 별을 잇는 데 걸린 시간과 실수를 기록합니다.

별자리 잇기 플레이

큰 화면

게임을 불러오는 중입니다.

5개에서 10개까지 6단계

1단계는 5개 별로 시작하고 단계가 올라갈 때마다 별이 하나씩 늘어 6단계는 10개입니다. 한 단계를 완료하면 다음 단계가 해금되고, 이후에는 해금된 단계 선택 목록에서 원하는 단계를 바로 다시 플레이할 수 있습니다.

다음 별과 연결선을 구분해 보세요

현재 눌러야 할 별은 강조 표시됩니다. 연결선은 이미 성공한 별끼리만 이어지며, 아직 누르지 않은 다음 별까지 미리 선을 그리지 않습니다. 숫자와 강조 표시를 보고 순서대로 진행하세요.

잘못 눌러도 진행은 유지됩니다

현재 순서가 아닌 별을 누르면 실수만 1회 늘고 이미 성공한 연결은 유지됩니다. HUD의 다음 별 번호를 확인한 뒤 계속 진행하면 됩니다.

최단 시간과 최소 실수

각 단계별 최단 완료 시간과 최소 실수를 별도로 저장합니다. 완료 시간은 정수 초 단위로 기록되며 최소 1초로 처리됩니다. 전체 완료 횟수와 최고 해금 단계도 브라우저에 저장됩니다.

되돌리기와 새 별자리

‘한 단계 되돌리기’는 마지막 성공 연결을 하나 취소하고 실수 1회를 추가합니다. ‘새 별자리’는 같은 단계에서 별 위치, 다음 번호, 실수와 경과 시간을 새로 시작합니다.

진행 저장과 탭 일시정지

진행 중에는 단계, 별 위치, 다음 번호, 실수와 경과 시간이 저장됩니다. 새로고침 후 유효한 저장 상태가 있으면 같은 배치를 복구하며, 다른 탭으로 이동한 동안은 시간이 증가하지 않습니다.

기록을 줄이는 방법

  • 현재 번호를 누르기 전에 다음 2~3개 별의 방향을 미리 확인하세요.
  • 숫자가 가까이 몰린 곳에서는 속도보다 번호 확인을 우선하세요.
  • 최단 시간 도전과 최소 실수 도전을 따로 진행하면 기록 변화를 해석하기 쉽습니다.
