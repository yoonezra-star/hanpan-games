12·16·24칸 세 단계

쉬움은 6쌍 12칸, 보통은 8쌍 16칸, 어려움은 12쌍 24칸입니다. 새 판을 시작하면 전체 카드가 잠깐 공개된 뒤 가려집니다. 난이도가 높을수록 미리 보기 시간이 짧아집니다.

쉬움6쌍 · 2.6초 공개
보통8쌍 · 1.9초 공개
어려움12쌍 · 1.3초 공개

최소 이동과 정확도

두 장을 열 때마다 이동 1회로 계산합니다. 서로 다른 그림이면 실수 1회가 추가되고, 정확도는 전체 이동 중 성공한 짝 맞추기 비율로 계산합니다. 난이도별 최소 이동, 최단 시간과 최고 정확도를 저장합니다.

다시 미리 보기

플레이 중 전체 위치를 2초 동안 다시 볼 수 있습니다. 연습용 기능이라 기록 경쟁에서는 사용하지 않고 푸는 편을 권합니다.

자동 저장과 키보드

카드 배치, 맞춘 위치, 한 장만 열어 둔 상태, 이동 수, 실수와 경과 시간을 저장합니다. 방향키로 카드 사이를 이동하고 Enter/Space로 뒤집을 수 있습니다. 탭이 숨겨지면 시간 측정을 멈춥니다.

공략 팁

  • 처음 공개 때 개별 아이콘보다 2×2 또는 행 단위로 묶어 기억하세요.
  • 한 번 본 카드가 나오면 짝 위치를 바로 회상해 실수 횟수를 줄입니다.
  • 모서리·중앙·가장자리처럼 기준점을 붙여 외우면 24칸에서 특히 유리합니다.
  • 최소 이동 기록을 노릴 때는 미리 보기를 추가 사용하지 않고 첫 공개에 집중하세요.

FAQ

새로고침하면 판이 바뀌나요?

한 장만 열어둔 상태도 저장되나요?

네. 첫 번째로 연 카드 위치도 저장합니다.
