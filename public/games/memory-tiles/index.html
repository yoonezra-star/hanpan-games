12·16·24칸 세 단계

쉬움은 6쌍 12칸, 보통은 8쌍 16칸, 어려움은 12쌍 24칸입니다. 새 판을 시작하면 전체 카드가 잠깐 공개된 뒤 가려집니다. 난이도가 높을수록 첫 공개 시간이 짧아집니다.

쉬움6쌍 · 4열 · 2.6초 공개
보통8쌍 · 4열 · 1.9초 공개
어려움12쌍 · 6열 · 1.3초 공개

이동과 정확도

첫 카드를 연 뒤 두 번째 카드를 열어 한 쌍을 비교할 때 이동 1회가 증가합니다. 서로 다른 그림이면 실수 1회가 추가됩니다. 정확도는 (이동 수-실수 수)÷이동 수 기준으로 계산하므로 쉬움의 이론적 최소 이동은 6회, 보통 8회, 어려움 12회입니다.

추가 미리 보기는 연습용입니다

플레이 중 전체 위치를 2초 동안 다시 볼 수 있고 그동안 타이머도 멈춥니다. 2026년 8월 27일 이후에는 이 기능을 사용한 판을 연습용으로 처리해 완주 횟수에는 포함하지만 최소 이동·최단 시간·최고 정확도 최고 기록은 갱신하지 않습니다.

자동 저장과 탭 일시정지

카드 배치, 맞춘 위치, 첫 번째로 연 카드, 이동 수, 실수, 경과 시간과 연습용 여부를 현재 브라우저에 저장합니다. 탭이 숨겨지면 타이머를 확실히 멈춘 상태로 저장하고 돌아오면 같은 판을 이어서 진행합니다.

키보드 조작

방향키로 카드 사이를 이동하고 Enter 또는 Space로 뒤집을 수 있습니다. 쉬움·보통은 4열, 어려움은 6열 보드에 맞춰 상하 이동 폭이 달라집니다.

기록 기준

난이도별 도전·완주, 최소 이동, 최단 시간과 최고 정확도를 저장합니다. 추가 미리 보기를 사용하지 않은 기록 도전 판만 최고 기록을 갱신합니다.

공략 팁

  • 처음 공개 때 개별 아이콘보다 2×2 또는 구역 단위로 묶어 기억하세요.
  • 모서리·중앙·가장자리처럼 위치 기준점을 먼저 정합니다.
  • 한 번 본 카드가 다시 나오면 직전 위치 정보를 바로 연결해 같은 카드를 반복 확인하지 않습니다.
  • 확실한 짝부터 제거하면 남은 카드 수가 줄어 기억 부담도 작아집니다.
  • 최소 이동이 안정된 뒤 같은 난이도에서 최단 시간을 줄이는 순서로 연습하세요.

FAQ

게임에 2분 제한이 있나요?

아니요. 현재 버전에는 고정 2분 제한이 없으며 모든 짝을 맞추면 끝납니다.

새로고침하면 판이 바뀌나요?

진행 중인 유효한 저장이 있으면 같은 카드 배치와 진행 상태를 복구합니다.

한 장만 열어둔 상태도 저장되나요?

네. 첫 번째로 연 카드 위치도 저장합니다.

추가 미리 보기를 쓰면 최고 기록이 갱신되나요?

아니요. 추가 미리 보기를 사용한 판은 연습용으로 완주만 기록하며 최고 기록 갱신에서는 제외합니다.
