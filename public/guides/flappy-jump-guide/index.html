플래피 점프 공략: 기둥 간격·중력·점프 리듬·기록 저장

플래피 점프는 Space·클릭·터치 한 번으로 상승 속도를 만들고, 입력하지 않는 동안 중력으로 내려오며 기둥 틈을 계속 통과하는 생존형 원버튼 게임입니다. 높은 기록을 내려면 빠른 연타보다 현재 상승·하강 상태와 다음 기둥 틈의 높이를 함께 읽는 것이 중요합니다.

업데이트 2026년 8월 27일 · 한판게임 플래피 점프 실제 런타임 기준

시간 제한 없이 충돌할 때까지 계속됩니다

현재 플래피 점프에는 60초나 1분 제한이 없습니다. 기체가 기둥 또는 화면 위·아래 경계와 충돌할 때 한 판이 끝납니다.

따라서 기록 목표는 제한 시간 동안 많이 누르는 것이 아니라 가능한 오래 살아남아 많은 기둥 쌍을 안전하게 통과하는 것입니다.

세 난이도는 틈·이동 속도·중력이 모두 다릅니다

쉬움기둥 틈 150px · 속도 2.3 · 중력 0.32
보통기둥 틈 125px · 속도 2.8 · 중력 0.36
어려움기둥 틈 105px · 속도 3.25 · 중력 0.40

어려움은 틈이 좁을 뿐 아니라 기둥이 더 빠르게 왼쪽으로 이동하고 중력도 강합니다. 같은 입력 간격을 그대로 사용하면 쉬움보다 빠르게 아래로 떨어지고 판단 시간도 줄어듭니다.

점프 한 번은 상승력을 더하는 대신 세로 속도를 -6.2로 재설정합니다

점프 입력이 들어오면 현재 상승 중인지 하강 중인지와 관계없이 기체의 세로 속도 vy가 -6.2로 바뀝니다. 입력하지 않는 동안에는 선택 난이도의 중력이 매 프레임 누적됩니다.

따라서 연속 입력이 상승력을 수학적으로 계속 더하는 것은 아닙니다. 하지만 상승 중 다시 누르면 -6.2가 반복 적용돼 높은 상태가 오래 유지되므로 과도한 연타는 위쪽 충돌로 이어질 수 있습니다.

Space를 길게 눌러 자동 점프하는 방식은 차단했습니다

브라우저는 키를 길게 누르면 동일한 keydown 이벤트를 반복 발생시킬 수 있습니다. 이전 구조에서는 Space를 누른 채 유지하는 것이 여러 점프 입력으로 처리될 수 있어 키보드 입력 방식에 따라 기록 조건이 달라질 여지가 있었습니다.

2026년 8월 27일부터 반복 keydown은 무시합니다. 한 번의 물리적인 Space 입력을 한 번의 점프로 취급하므로 직접 리듬을 만들어야 합니다.

기둥 쌍은 약 1.45초마다 새로 생성됩니다

새 기둥 쌍의 생성 주기는 약 1,450ms로 세 난이도에서 같습니다. 기둥 폭은 56px이며 화면 오른쪽 바깥에서 생성되어 난이도별 속도로 왼쪽으로 이동합니다.

생성 주기는 같아도 어려움은 이동 속도가 빠르기 때문에 화면에 나타난 뒤 기체까지 도달하는 시간이 더 짧습니다. 다음 틈을 확인하고 높이를 조절할 수 있는 실질적인 판단 시간이 줄어듭니다.

기둥 틈 높이는 무작위지만 너무 위·아래로 붙지 않게 제한됩니다

기둥의 위쪽 끝은 기본적으로 화면 상단에서 약 60px 이상 떨어진 범위에서 무작위로 정해집니다. 틈의 아래쪽 끝도 대체로 y=380보다 아래로 내려가지 않도록 생성 범위를 제한합니다.

그래서 틈 높이는 매번 달라지지만 화면 최상단이나 바닥 바로 위에 극단적으로 붙는 구조는 아닙니다. 그래도 연속 기둥의 높이 차이는 생길 수 있으므로 현재 기둥만 보지 말고 다음 틈을 미리 확인해야 합니다.

첫 목표는 기둥 중앙보다 작은 상하 진폭입니다

기체가 크게 올라갔다가 크게 떨어지는 패턴은 쉬움에서는 버틸 수 있어도 125px·105px 틈에서는 다음 높이에 대응하기 어렵습니다.

기둥 중앙을 정확히 한 점처럼 맞히는 것보다 위·아래 여유가 함께 남는 좁은 높이 범위 안에서 기체가 움직이도록 만드는 편이 안정적입니다.

하강이 시작되는 순간을 기준으로 보정합니다

상승 중 연속으로 누르기보다 기체가 내려오기 시작했을 때 한 번 눌러 상승 속도를 다시 만드는 방식이 리듬을 읽기 쉽습니다.

초보자는 ‘한 번 점프 → 기다림 → 하강 확인 → 다시 한 번’의 기본 주기를 먼저 익힌 뒤, 다음 틈이 높으면 조금 일찍, 낮으면 조금 늦게 누르는 방식으로 조절하세요.

점수는 기둥 쌍의 오른쪽 끝을 완전히 지난 뒤 올라갑니다

기체가 틈 안으로 들어갔다고 즉시 1점이 생기지 않습니다. 기둥 쌍의 오른쪽 끝이 기체 중심 x 위치보다 완전히 왼쪽으로 지나간 순간 그 기둥을 한 번만 통과 처리합니다.

따라서 틈에 진입한 직후 다음 기둥을 보더라도 현재 기둥 후단을 완전히 벗어날 때까지는 높이를 급격히 바꾸지 않는 편이 좋습니다.

통과하는 순간 최고 기록과 누적 통과를 바로 저장합니다

2026년 8월 27일부터 기둥 하나를 실제로 통과하는 순간 현재 판 점수가 기존 best보다 높으면 최고 기록을 갱신하고, total도 1 증가시킨 뒤 즉시 로컬 저장합니다.

이전에는 충돌로 판이 끝날 때 현재 점수를 한꺼번에 누적했기 때문에, 진행 중 새로고침하거나 플레이 허브에서 다른 게임으로 이동하면 이미 통과한 기둥이 누적 기록에서 사라질 수 있었습니다. 지금은 실제 통과 자체를 기록 이벤트로 사용합니다.

도전 횟수는 비행 시작 순간 저장됩니다

난이도를 선택하고 비행 시작을 누르면 해당 난이도의 attempts가 즉시 1 증가합니다. 시작 후 바로 새로고침해도 도전 횟수는 남습니다.

반면 현재 기체 높이·기둥 위치·현재 판 점수를 복원하는 인게임 세이브는 없습니다. 새로고침 후에는 새 비행을 시작해야 합니다.

위·아래 화면 경계도 즉시 게임 오버 조건입니다

기체 중심 y가 약 12px보다 위로 올라가거나 408px보다 아래로 내려가면 충돌로 판이 끝납니다. 화면 아래 지면은 약 y=420부터 그려집니다.

높은 틈을 따라간다고 화면 꼭대기까지 올라갈 필요는 없고, 낮은 틈으로 내려갈 때도 너무 오래 입력을 쉬어 아래 경계를 건드리지 않도록 해야 합니다.

기둥 충돌은 기체 중심에서 약 13px 범위를 봅니다

기체는 화면에서 반지름 약 14px 원으로 그려지며, 기둥 충돌에서는 중심 기준 약 13px 범위를 사용합니다. 기둥 폭은 56px입니다.

어려움 105px 틈은 숫자만 보면 넓어 보여도 기체 크기를 제외하면 실제 상하 여유가 크게 줄어듭니다. 틈 가장자리를 스치기보다 가능한 가운데 쪽을 통과하세요.

일시정지는 화면 버튼 또는 P로 제어합니다

2026년 8월 27일부터 일시정지 버튼과 P 키를 지원합니다. 정지 중에는 중력·기둥 이동이 멈추고 Space·캔버스 터치·점프 버튼도 새 점프를 만들지 않습니다.

P를 길게 눌렀을 때 발생하는 자동반복도 무시합니다. 다시 계속하면 기준 시간을 현재 시점으로 재설정해 정지해 있던 시간이 큰 프레임 이동으로 합산되지 않습니다.

탭을 벗어나면 자동 정지되지만 돌아와도 자동 재개되지 않습니다

진행 중 브라우저 탭이 숨겨지면 게임은 자동으로 일시정지됩니다. 이전에는 탭으로 돌아오는 순간 자동으로 다시 움직여 사용자가 준비하기 전에 낙하하거나 충돌할 수 있었습니다.

현재는 탭으로 돌아와도 정지 상태를 유지합니다. 준비한 뒤 계속 버튼 또는 P 키로 직접 재개해야 합니다.

난이도별 운영 방법

쉬움: 일정한 리듬부터 익힙니다

150px 틈과 가장 느린 기둥, 낮은 중력으로 보정 여유가 큽니다. 연타 없이 5개, 10개를 통과하며 움직임 폭을 작게 만드는 데 집중하세요.

보통: 현재 기둥을 지나기 전에 다음 틈을 봅니다

125px 틈에서는 현재 기둥을 완전히 통과한 뒤 다음 높이를 확인하면 늦을 수 있습니다. 현재 진입이 안정되면 다음 틈을 보고 출구 높이를 미리 준비하세요.

어려움: 큰 복구보다 작은 수정이 안전합니다

105px 틈, 속도 3.25, 중력 0.40이 함께 적용됩니다. 크게 떨어진 뒤 여러 번 눌러 복구하는 방식보다 작은 상하 진폭을 유지하는 편이 생존 확률이 높습니다.

입력 방식

  • Space: 한 번 눌러 점프합니다. 자동반복 입력은 무시합니다.
  • 캔버스 클릭·터치: 한 번 누를 때 한 번 점프합니다.
  • 점프 버튼: 화면 버튼으로 같은 점프를 실행합니다.
  • P / 일시정지 버튼: 진행 중 정지·계속을 전환합니다.

브라우저에 저장되는 기록

  • hanpan-flappy-records-v2: 난이도별 attempts, best, total
  • hanpan-flappy-prefs-v2: 마지막 선택 difficulty

브라우저 데이터를 삭제하거나 다른 브라우저·기기로 이동하면 로컬 기록은 자동으로 옮겨지지 않습니다.

자주 실패하는 패턴

  • 상승 중 연타: 위쪽 경계까지 너무 높게 올라갈 수 있습니다.
  • 현재 기둥만 봄: 통과 직후 다음 틈 높이에 대응이 늦습니다.
  • 큰 낙하 뒤 급복구: 여러 번의 점프로 상하 진폭이 더 커집니다.
  • 틈에 진입하자마자 성공으로 판단: 기둥 후단과 충돌할 수 있습니다.
  • 탭 복귀 즉시 입력을 예상: 현재는 자동 재개되지 않으므로 계속 후 점프해야 합니다.

초보자 연습 순서

  1. 쉬움에서 기둥 없이 움직인다고 생각하고 점프·하강 리듬을 익힙니다.
  2. 5개 연속 통과까지 상하 진폭을 줄이는 데 집중합니다.
  3. 현재 기둥 진입이 안정되면 다음 틈을 미리 보는 습관을 만듭니다.
  4. 보통에서 같은 리듬을 사용하되 하강 보정 시점을 조금 앞당깁니다.
  5. 어려움에서는 기록보다 작은 높이 수정과 중앙 통과를 우선합니다.

플래피 점프 FAQ

플래피 점프는 1분 게임인가요?

아닙니다. 시간 제한 없이 충돌할 때까지 이어지는 생존형 게임입니다.

Space를 계속 누르고 있으면 자동으로 점프하나요?

아닙니다. 2026년 8월 27일부터 키 자동반복을 무시해 한 번의 실제 Space 입력만 한 번의 점프로 처리합니다.

점프를 여러 번 누르면 힘이 계속 더해지나요?

아닙니다. 매 점프가 세로 속도를 -6.2로 다시 설정합니다. 다만 상승 중 다시 누르면 높은 상태가 오래 유지될 수 있습니다.

언제 1점이 올라가나요?

기둥 쌍의 오른쪽 끝이 기체 중심보다 완전히 왼쪽으로 지나간 순간 1점이 올라갑니다.

통과한 뒤 바로 새로고침해도 최고 기록이 남나요?

네. 현재는 기둥 통과 순간 최고 기록과 누적 통과를 즉시 저장합니다.

탭을 나갔다 돌아오면 바로 움직이나요?

아닙니다. 탭이 숨겨지면 자동 일시정지되고 돌아온 뒤에도 정지 상태를 유지합니다. 계속 버튼 또는 P로 직접 재개해야 합니다.

진행 중 판을 새로고침 후 이어서 할 수 있나요?

현재 기체와 기둥 상태는 복원되지 않습니다. 이미 저장된 도전·최고·누적 기록과 난이도 선택만 유지됩니다.
