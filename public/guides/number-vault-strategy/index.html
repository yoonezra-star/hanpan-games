Number Vault Strategy

숫자 금고 공략: 1~500 UP/DOWN·중간값·최소 시도·저장

숫자 금고는 숨은 정수를 맞힐 때마다 UP 또는 DOWN 힌트를 받아 후보 범위를 줄이는 숫자 추리 게임입니다. 감으로 숫자를 여러 개 찍기보다 남은 범위의 중간값을 반복해서 선택하면 제한된 시도 안에서 정답에 도달할 가능성을 가장 안정적으로 높일 수 있습니다.

업데이트 2026년 8월 27일 · 한판게임 숫자 금고 실제 런타임 기준

난이도는 범위와 최대 시도 횟수로 나뉩니다

쉬움1~50 · 최대 8회 · 이론 기준 6회
보통1~100 · 최대 7회 · 이론 기준 7회
어려움1~500 · 최대 9회 · 이론 기준 9회

쉬움은 후보 50개, 보통은 100개, 어려움은 500개에서 시작합니다. 각 난이도는 정답을 맞히거나 최대 시도 횟수를 모두 사용할 때 한 판이 끝납니다.

현재 숫자 금고에는 1분처럼 고정된 전체 시간 제한이 없습니다. 기록을 비교할 때는 플레이 시간보다 몇 번의 유효한 추측으로 해제했는지를 보는 편이 실제 게임 구조에 맞습니다.

새 금고를 시작할 때 정답과 후보 범위가 만들어집니다

새 금고를 누르면 선택한 난이도 범위 안에서 숨은 정수 하나가 무작위로 정해지고, 후보의 하한과 상한이 난이도 전체 범위로 초기화됩니다. 이때 난이도별 도전 횟수도 1 증가합니다.

쉬움이라면 1~50, 보통은 1~100, 어려움은 1~500이 첫 후보 범위가 됩니다. 이후 유효한 추측을 제출할 때마다 UP/DOWN 결과에 맞춰 이 범위가 좁아집니다.

UP과 DOWN은 이미 확인한 영역을 후보에서 제거합니다

입력한 숫자가 정답보다 작으면 UP이 나오고 그 숫자 이하가 후보에서 제외됩니다. 입력값이 정답보다 크면 DOWN이 나오고 그 숫자 이상이 후보에서 제외됩니다.

예를 들어 1~100에서 50을 입력해 UP이 나오면 새 후보는 51~100입니다. 이어서 75에서 DOWN이 나오면 51~74만 남습니다. 이미 제외된 영역은 다시 검토할 필요가 없습니다.

중간값을 반복해서 고르는 것이 기본 전략입니다

정답에 대한 추가 정보가 없는 상태에서는 남은 범위의 가운데 값을 고르는 방법이 가장 안정적입니다. UP과 DOWN 어느 쪽이 나오더라도 후보를 비슷한 크기로 나눌 수 있기 때문입니다.

첫 시도는 쉬움 25, 보통 50, 어려움 250 근처에서 시작할 수 있습니다. 이후에는 첫 숫자를 계속 기준으로 삼지 말고 새로 좁아진 범위의 중간을 다시 계산해야 합니다.

중간값 입력 버튼은 제출이 아니라 입력 보조 기능입니다

중간값 입력은 현재 후보 하한과 상한을 더한 뒤 2로 나눈 값의 내림 정수를 입력 칸에 넣습니다. 버튼을 눌렀다고 시도 횟수가 증가하거나 정답 판정이 실행되지는 않습니다.

숫자가 입력된 뒤 해제 시도를 누르거나 입력 칸에서 Enter를 눌러야 실제 추측으로 처리됩니다. 중간값 계산이 익숙하지 않은 초보자는 이 버튼을 이용해 범위를 절반씩 줄이는 패턴부터 익히면 좋습니다.

후보 범위 밖 숫자와 정수가 아닌 값은 시도를 소비하지 않습니다

현재 후보 범위 밖의 숫자나 정수가 아닌 값은 유효한 추측으로 처리되지 않습니다. 게임은 현재 후보 범위 안의 정수를 입력하라고 안내하고 사용 시도 횟수는 그대로 유지합니다.

예를 들어 후보가 51~74인데 50을 다시 입력해도 한 번의 시도로 계산되지 않습니다. 다만 기록을 줄이려면 이미 제외된 숫자를 다시 생각하지 않는 습관 자체를 만드는 편이 좋습니다.

이론적 이진 탐색 기준은 6·7·9회입니다

HUD의 최적 기준은 현재 난이도 전체 후보 수에 대해 ceil(log2(후보 수)) 방식으로 계산됩니다. 후보 50개는 6회, 100개는 7회, 500개는 9회입니다.

이 값은 모든 판이 반드시 그 횟수에 끝난다는 뜻이 아닙니다. 정답이 첫 중간값에 있으면 1회 만에 끝날 수도 있습니다. 반대로 중간에서 크게 벗어난 추측을 반복하면 기준보다 많은 시도를 사용할 수 있습니다.

쉬움은 이진 탐색 원리를 익힐 여유가 있습니다

쉬움은 1~50에서 최대 8회까지 사용할 수 있어 이론 기준 6회보다 두 번의 여유가 있습니다. 처음에는 최소 시도보다 UP/DOWN 뒤에 후보 범위를 정확히 다시 읽는 연습에 집중하는 편이 좋습니다.

여러 판을 6~7회 안쪽으로 안정적으로 해결할 수 있다면 중간값 전략이 어느 정도 익숙해졌다고 볼 수 있습니다.

보통은 7회 제한과 이론 기준이 같습니다

보통은 1~100에서 최대 7회이고 이론 기준도 7회입니다. 따라서 첫 수부터 크게 치우치거나, 힌트를 받은 뒤 남은 범위를 절반에 가깝게 나누지 못하면 마지막에 시도가 부족해지기 쉽습니다.

50 근처에서 시작하고 매번 새 범위의 중간을 다시 고르는 기본 루틴을 가장 분명하게 연습할 수 있는 난이도입니다.

어려움도 후보 수만 많을 뿐 원리는 같습니다

어려움은 1~500이라 숫자가 크게 느껴지지만 이진 탐색 방식은 바뀌지 않습니다. 250을 기준으로 시작해 남은 범위를 다시 절반씩 나누면 후보 수가 빠르게 줄어듭니다.

최대 시도와 이론 기준이 모두 9회이므로 직감으로 치우친 숫자를 여러 번 선택할 여유는 적습니다. 화면의 현재 후보 범위를 그대로 믿고 중간값 루틴을 유지하는 것이 중요합니다.

최소 시도 기록은 가장 적게 사용한 성공 횟수입니다

성공한 판마다 사용한 시도 횟수를 확인해 기존 최소 기록보다 작으면 난이도별 best 기록을 갱신합니다. 첫 추측이 우연히 정답과 같다면 1회 기록도 나올 수 있습니다.

따라서 최소 시도 한 번만 보고 전략이 좋아졌다고 단정하기보다 여러 판에서 이론 기준 근처를 얼마나 꾸준히 유지하는지도 함께 보는 편이 좋습니다.

최적권 성공은 이론 기준 + 1회 안의 성공을 셉니다

현재 런타임은 성공할 때 사용 시도가 해당 난이도의 이론 기준보다 1회 이내라면 optimalWins를 1 증가시킵니다.

  • 쉬움: 이론 기준 6회이므로 7회 이내 성공이 최적권 성공입니다.
  • 보통: 계산 기준은 8회 이내지만 최대 시도가 7회라 성공한 모든 판이 최적권에 들어갑니다.
  • 어려움: 계산 기준은 10회 이내지만 최대 시도가 9회라 성공한 모든 판이 최적권에 들어갑니다.

그래서 최적권 성공은 특히 쉬움에서 이진 탐색 기준에 가까운 해결을 구분하는 의미가 더 큽니다. 보통과 어려움에서는 성공 횟수와 거의 같은 흐름으로 늘어납니다.

현재 연승과 최고 연승은 서로 다른 값입니다

같은 페이지에서 한 판을 성공하면 현재 연승이 1 증가하고 다음 금고에서도 성공하면 계속 올라갑니다. 시도 횟수를 모두 사용해 실패하거나 난이도를 변경하면 현재 연승은 0으로 초기화됩니다.

난이도별 최고 연승은 bestStreak로 장기 기록에 저장됩니다. 반면 현재 연승 자체는 완료된 판의 장기 기록 필드가 아닙니다. 진행 중인 판을 저장할 때는 복구를 위해 현재 연승도 함께 저장합니다.

완료 직후 새로고침하면 현재 연승은 0부터 다시 시작합니다

진행 중인 판은 현재 연승을 포함해 저장하지만 성공 또는 실패로 판이 끝나면 진행 저장 키를 삭제합니다. 따라서 성공 직후 다음 금고를 시작하지 않은 상태에서 페이지를 새로고침하면 현재 연승은 복원되지 않습니다.

다만 이미 갱신된 최고 연승은 난이도별 장기 기록에 남습니다. 현재 연승과 최고 연승을 구분하면 새로고침 뒤 숫자가 달라지는 이유를 이해하기 쉽습니다.

진행 중 금고는 새로고침 후 자동 복구됩니다

유효한 진행 저장이 있으면 페이지를 다시 열 때 선택 난이도, 숨은 정답, 현재 후보 범위, 이전 오답 이력, 사용 시도 횟수와 현재 연승을 복구합니다. 복구 과정에서는 새 도전 횟수를 추가하지 않습니다.

그래서 진행 중 새로고침은 판을 처음부터 다시 만드는 기능이 아닙니다. 새 문제를 원한다면 새 금고를 사용하거나 난이도를 변경해야 합니다.

아직 제출하지 않은 입력값은 새로고침으로 복구되지 않습니다

자동 저장은 실제 게임 상태를 저장하지만 입력 칸에 적어 놓고 아직 제출하지 않은 숫자까지 저장하지는 않습니다. 새로고침하면 마지막으로 확정된 후보 범위와 추측 이력까지만 돌아옵니다.

중간값 버튼으로 숫자만 채워 놓은 상태 역시 아직 유효한 시도가 아니므로 새로고침 뒤에는 입력 칸이 비어 있습니다.

새 금고를 진행 중에 누르면 현재 문제를 바로 교체합니다

현재 판을 끝내기 전에 새 금고를 누르면 새 정답과 전체 후보 범위가 만들어지고 새 도전 횟수가 증가합니다. 이전 진행 저장은 새 판 상태로 덮어써집니다.

현재 런타임은 이 중도 교체를 별도의 실패나 성공으로 기록하지 않습니다. 기록을 의미 있게 비교하려면 한 판을 시작한 뒤에는 가능하면 성공 또는 최대 시도까지 마친 다음 새 금고로 넘어가는 편이 좋습니다.

난이도를 바꾸면 진행 판과 현재 연승이 초기화됩니다

난이도를 변경하면 진행 저장 키가 삭제되고 새 난이도의 전체 후보 범위로 돌아갑니다. 현재 판의 정답, 오답 이력, 사용 시도 횟수와 현재 연승도 초기화됩니다.

난이도별 장기 기록은 서로 별도로 남아 있으므로 쉬움에서 난이도를 바꿨다고 기존 쉬움의 성공·최소 시도·최고 연승 기록이 지워지지는 않습니다.

브라우저 저장 키는 진행·기록·설정으로 나뉩니다

현재 숫자 금고는 세 개의 로컬 저장소 키를 사용합니다.

  • hanpan-number-vault-save-v2: 진행 중인 판의 버전, 난이도, 정답, 후보 하한·상한, 오답 이력, 사용 시도, 현재 연승을 저장합니다.
  • hanpan-number-vault-records-v2: 난이도별 attempts, wins, best, bestStreak, optimalWins를 저장합니다.
  • hanpan-number-vault-prefs-v2: 선택 난이도와 소리 끄기 여부를 저장합니다.

이 기록은 현재 브라우저의 localStorage에 저장되는 로컬 기록입니다. 다른 기기나 다른 브라우저로 자동 동기화되는 온라인 순위표 구조는 아닙니다.

도전 횟수는 새 금고를 시작하는 순간 저장됩니다

난이도별 attempts는 첫 추측을 제출했을 때가 아니라 새 금고가 만들어지는 순간 1 증가합니다. 반면 wins, 최소 시도, 최고 연승, 최적권 성공은 실제로 정답을 맞힌 성공 판에서 갱신됩니다.

따라서 새 금고를 여러 번 열고 중간에 교체하면 도전 횟수만 늘어날 수 있습니다. 성공률을 비교하려면 판을 중간에 버리지 않고 완료하는 습관이 더 정확합니다.

오답 이력에는 UP/DOWN이 나온 추측만 남습니다

플레이 화면의 추측 이력에는 정답보다 작거나 컸던 숫자와 UP/DOWN 방향이 순서대로 표시됩니다. 정답을 맞힌 마지막 숫자는 오답 이력 배열에 추가되지 않습니다.

후보 범위 숫자만 봐도 다음 입력은 정할 수 있지만, 이력을 함께 보면 어느 선택 때문에 범위가 현재 상태가 되었는지 되짚기 쉽습니다.

조작은 숫자 입력과 버튼, Enter를 사용합니다

숫자를 입력한 뒤 해제 시도 버튼을 누르거나 입력 칸에서 Enter를 누르면 추측이 제출됩니다. 화면 전체를 누르는 방식이나 방향키 조작은 사용하지 않습니다.

모바일 입력 칸은 숫자 키패드를 요청하는 설정을 사용합니다. 작은 화면에서는 숫자를 입력한 뒤 현재 후보 범위 안의 값인지 한 번 확인하고 제출하면 잘못된 입력을 줄일 수 있습니다.

탭을 벗어나도 별도의 타이머 취소 동작은 없습니다

숫자 금고는 반응속도 게임처럼 브라우저 탭 이탈을 따로 감지해 회차를 취소하는 구조가 아닙니다. 고정 시간 제한이 없기 때문에 다른 탭을 보고 돌아와도 진행 중인 후보 범위와 시도 횟수는 그대로입니다.

페이지 자체를 새로고침하거나 다시 열면 localStorage의 진행 저장을 사용해 마지막 확정 상태를 복구합니다.

모바일에서는 계산보다 후보 범위 확인을 우선합니다

모바일에서는 화면이 좁아 이전 이력과 입력 칸을 번갈아 보게 될 수 있습니다. 직접 중간값을 계산하다 입력 실수가 반복된다면 먼저 중간값 입력을 사용해 범위를 줄이는 흐름을 익히는 편이 좋습니다.

기록을 비교할 때는 같은 난이도에서 직접 계산했는지 중간값 버튼을 사용했는지도 자신만의 기준을 정해 두면 연습 변화를 더 일관되게 볼 수 있습니다.

자주 생기는 실패 패턴

  • 첫 숫자를 한쪽 끝에서 시작하기: 한 방향의 힌트가 나오면 후보가 거의 줄지 않을 수 있습니다.
  • 고정 간격으로 이동하기: 50→60→70처럼 같은 크기로 움직이면 남은 후보 수에 맞춰 탐색 폭을 조절하지 못합니다.
  • 이미 제외된 숫자를 다시 생각하기: UP/DOWN으로 버린 범위는 다음 판단에서 완전히 제외하는 편이 좋습니다.
  • 최소 시도 한 번만 보기: 우연히 초반에 정답을 맞힌 판보다 여러 판의 안정적인 해결 횟수가 전략을 보기 좋습니다.
  • 진행 중 새 금고를 반복하기: 도전 횟수만 늘 수 있어 성공률과 연승 기록을 해석하기 어려워집니다.
  • 난이도를 섞어 기록 비교하기: 후보 수와 최대 시도가 다르므로 같은 난이도끼리 비교해야 합니다.

초보자용 연습 순서

  1. 쉬움: 첫 수를 25 근처로 두고 UP/DOWN 뒤 후보 범위를 확인합니다.
  2. 중간값 버튼: 새 범위가 생길 때마다 중간값 입력을 사용해 후보가 절반씩 줄어드는 흐름을 익힙니다.
  3. 직접 계산: 6~7회 근처에서 안정적으로 성공하면 중간값을 직접 계산합니다.
  4. 보통: 7회 제한 안에서 같은 루틴을 유지합니다.
  5. 어려움: 1~500이라는 숫자에 흔들리지 말고 남은 범위를 계속 절반으로 나눕니다.
  6. 기록 확인: 최소 시도 하나보다 성공률·최고 연승·같은 난이도의 반복 결과를 함께 봅니다.

FAQ

숫자 금고는 1분 안에 풀어야 하나요?

아니요. 현재 런타임에는 고정 전체 시간 제한이 없습니다. 쉬움 8회, 보통 7회, 어려움 9회의 최대 유효 추측 횟수가 종료 기준입니다.

가장 좋은 첫 숫자는 무엇인가요?

추가 정보가 없다면 현재 범위의 중간값이 가장 안정적입니다. 쉬움은 25, 보통은 50, 어려움은 250 근처에서 시작할 수 있습니다.

범위 밖 숫자를 입력하면 시도가 줄어드나요?

아니요. 현재 후보 범위 밖의 값이나 정수가 아닌 값은 유효한 추측으로 처리하지 않아 사용 시도 횟수가 증가하지 않습니다.

중간값 입력을 누르면 자동으로 제출되나요?

아니요. 현재 후보 범위의 가운데 정수를 입력 칸에 넣어 줄 뿐입니다. 해제 시도 버튼이나 Enter로 직접 제출해야 합니다.

새로고침하면 진행 중인 정답이 바뀌나요?

유효한 진행 저장이 있으면 같은 정답, 후보 범위, 오답 이력과 사용 시도 횟수를 복구합니다. 제출하지 않은 입력 칸의 숫자는 복구하지 않습니다.

최고 연승과 현재 연승은 모두 저장되나요?

난이도별 최고 연승은 장기 기록에 저장됩니다. 현재 연승은 진행 중 판의 복구 데이터에는 포함되지만 완료된 판 뒤 진행 저장이 삭제되므로, 완료 직후 새로고침하면 현재 연승은 0부터 다시 시작합니다.

최적권 성공이 보통과 어려움에서 성공 횟수와 비슷한 이유는 무엇인가요?

최적권 기준은 이론 기준 + 1회입니다. 보통은 8회, 어려움은 10회 이내가 계산 기준인데 실제 최대 시도가 각각 7회와 9회라 성공하면 모두 최적권 조건 안에 들어갑니다.
