클릭 스프린트 공략: 5·10·20초 CPS·1초 버스트·페이스

클릭 스프린트는 정해진 시간 동안 클릭·터치 또는 Space 입력을 반복해 전체 클릭 수와 CPS를 측정하는 기록 게임입니다. 한 번의 최고 1초만 보는 대신 전체 CPS와 1초별 구간, 전후반 페이스를 함께 보면 순간 속도와 유지력을 나눠서 볼 수 있습니다.

업데이트 2026년 8월 27일 · 한판게임 클릭 스프린트 실제 런타임 기준

세 모드는 측정 시간만 다르고 기록은 따로 관리됩니다

5초짧은 버스트와 순간 입력 속도
10초기본 CPS와 지속 리듬 비교
20초후반까지 유지되는 페이스 확인

5초·10초·20초는 같은 입력 로직을 사용하지만 측정 시간이 다릅니다. 브라우저 최고 기록도 시간 모드마다 별도로 저장되므로 5초 기록이 20초 기록을 덮어쓰지 않습니다.

개인 기록 변화를 확인할 때는 같은 시간 모드끼리 비교하는 편이 좋습니다. 5초는 피로가 쌓이기 전에 끝나기 때문에 순간 속도에 유리하고, 20초는 후반의 리듬 유지가 결과에 더 많이 드러납니다.

READY 상태에서 첫 입력은 클릭 수가 아니라 시작 신호입니다

측정을 시작하는 방법은 두 가지입니다. READY 상태에서 큰 패드를 클릭·터치하거나 Space를 누르면 그 입력이 타이머를 시작하지만 클릭 수는 0에서 시작합니다. 첫 입력 자체는 기록에 포함되지 않습니다.

반대로 스프린트 시작 버튼을 먼저 누르면 버튼을 누른 순간부터 시간이 흐르고, 그다음 패드나 Space 입력부터 클릭 수가 증가합니다. 기록을 반복 비교할 때는 매번 같은 시작 방식을 사용하는 것이 조건을 맞추기 쉽습니다.

진행 중 CPS와 최종 CPS의 분모가 다릅니다

진행 중 HUD의 CPS는 현재 클릭 수를 실제 경과 시간으로 나눕니다. 시작 직후에는 경과 시간이 매우 짧아 값이 크게 흔들릴 수 있으므로 초반 숫자를 최종 기록처럼 해석하지 않는 것이 좋습니다.

측정이 완료되면 최종 CPS는 총 클릭 수 ÷ 선택한 전체 시간으로 계산합니다. 예를 들어 10초 모드에서 72회를 기록하면 최종 CPS는 7.20입니다. 5초에서 36회도 7.20 CPS지만 측정 시간이 다르므로 장기 비교는 같은 모드 안에서 하는 편이 적절합니다.

총 클릭 수와 CPS는 같은 모드에서는 함께 움직입니다

한 시간 모드 안에서는 분모가 항상 같기 때문에 클릭 수가 많아지면 최종 CPS도 함께 올라갑니다. 그래서 최고 클릭과 최고 CPS는 같은 지속 기록을 서로 다른 단위로 보여 주는 성격이 강합니다.

반면 최고 1초 버스트는 별도 기록입니다. 전체 클릭 수가 이전보다 낮더라도 특정 한 초에 더 많은 입력을 했다면 최고 1초 기록만 갱신될 수 있습니다.

1초 구간은 순간 속도가 어디서 올라가고 떨어지는지 보여 줍니다

게임은 경과 시간을 약 50ms 간격으로 확인하면서 지나간 1초 구간의 클릭 수를 분리합니다. 화면에는 1초 7, 2초 8처럼 구간별 입력 수가 표시되고, 그중 가장 큰 값이 현재 도전의 최고 1초가 됩니다.

10초 동안 70회를 기록했더라도 구간이 10, 9, 8, 7, 7, 7, 6, 6, 5, 5처럼 계속 떨어진다면 초반 버스트는 빠르지만 유지력이 줄어드는 패턴으로 볼 수 있습니다. 반대로 구간 차이가 작다면 전체 리듬이 비교적 일정한 편입니다.

페이스 표시는 구간 수 차이를 평균으로 보정합니다

현재 페이스 표시는 앞쪽 1초 구간과 뒤쪽 1초 구간의 평균 클릭 수를 비교합니다. 뒤쪽 평균이 앞쪽보다 같거나 높으면 후반↑, 낮으면 초반↑가 표시됩니다.

  • 5초: 앞 3개 구간 평균과 뒤 2개 구간 평균을 비교합니다.
  • 10초: 앞 5개와 뒤 5개 구간 평균을 비교합니다.
  • 20초: 앞 10개와 뒤 10개 구간 평균을 비교합니다.

5초는 앞뒤 구간 수가 같지 않지만 총합이 아니라 각각의 평균으로 비교하므로 3초 쪽이 단순히 한 구간 더 많다는 이유로 유리해지지 않습니다. 뒤쪽 구간이 아직 생기지 않은 초반에는 페이스 판단을 표시하지 않습니다.

Space는 직접 반복해서 누른 입력만 셉니다

키보드에서는 Space를 사용할 수 있습니다. 다만 Space를 누른 채 유지했을 때 운영체제나 브라우저가 발생시키는 자동 반복 keydown 이벤트는 현재 런타임에서 제외합니다.

따라서 마우스의 연속 pointer 입력처럼 키보드도 사용자가 직접 반복해서 누른 입력을 기준으로 측정합니다. 키를 누르고 있기만 해서 CPS가 자동으로 올라가는 방식은 기록 비교에 사용되지 않습니다.

클릭·터치·Space는 같은 기록판을 쓰지만 장치는 구분해서 비교합니다

큰 패드는 pointerdown으로 입력을 받아 마우스 클릭과 터치를 처리합니다. Space도 같은 클릭 수 증가 로직으로 들어가지만 실제 하드웨어의 반발력, 터치 지연, 손가락 움직임은 서로 다릅니다.

그래서 개인 기록을 볼 때는 10초 + 같은 마우스, 10초 + 같은 키보드처럼 조건을 최대한 고정하는 것이 좋습니다. 입력 장치를 바꾼 직후 결과가 변했다면 손의 속도만 변했다고 단정하기 어렵습니다.

도전 횟수는 시작할 때 즉시 증가합니다

각 시간 모드의 attempts는 측정을 정상 완료했을 때가 아니라 측정을 시작할 때 1 증가하고 즉시 브라우저에 저장됩니다. READY 패드 첫 입력으로 시작하든 시작 버튼으로 시작하든 동일합니다.

따라서 10초를 시작한 뒤 4초쯤에 탭을 벗어나 도전이 중단되어도 도전 횟수는 이미 증가한 상태로 남을 수 있습니다. 여기서 도전 횟수는 완료 판 수가 아니라 시작한 측정 횟수에 가깝습니다.

최고 기록은 정해진 시간을 끝낸 판에서만 갱신됩니다

5·10·20초가 끝까지 지나면 현재 총 클릭 수, 최종 CPS, 최고 1초를 계산합니다. 그때 기존 기록보다 좋다면 bestClicks, bestCps, bestBurst를 각각 갱신합니다.

탭 이탈이나 시간 모드 변경 등으로 중간에 끝난 도전은 최고 기록 갱신 단계에 들어가지 않습니다. 중간 몇 초의 높은 CPS가 브라우저 최고 CPS로 남지 않는 이유입니다.

탭을 벗어나면 현재 측정은 일시정지가 아니라 중단됩니다

측정 중 문서가 숨겨지면 타이머를 멈추고 started 상태를 해제합니다. 다시 탭으로 돌아와도 남은 시간을 이어서 재개하지 않습니다. 새 도전을 시작해야 합니다.

이 방식은 백그라운드 탭에서 브라우저 타이머가 느려지거나 사용자가 화면을 보지 않은 시간이 결과에 섞이는 것을 막는 데 도움이 됩니다. 이미 저장된 과거 최고 기록은 탭 이탈 때문에 삭제되지 않습니다.

새로고침해도 진행 중 클릭 수는 복구되지 않습니다

클릭 스프린트에는 진행 중 클릭 수, 시작 시각, 1초 구간을 보관하는 별도 세이브 키가 없습니다. 새로고침하면 진행 중이던 도전은 처음부터 다시 해야 합니다.

반면 선택한 시간 모드와 장기 기록은 localStorage에 남습니다. 진행 상태와 완료 기록을 구분해서 보면 새로고침 후 무엇이 유지되는지 이해하기 쉽습니다.

브라우저 저장 키와 기록 필드

시간 모드별 장기 기록은 hanpan-click-sprint-records-v2 키를 사용합니다. 각 5초·10초·20초 모드에 attempts, bestClicks, bestCps, bestBurst가 저장됩니다.

선택한 시간 모드는 hanpan-click-sprint-prefs-v2에 mode 필드로 저장합니다. 현재 런타임에는 별도 음소거 설정이나 진행 자동저장 필드가 없습니다.

시간 모드를 바꾸면 진행 측정은 초기화됩니다

측정 중 5초·10초·20초 선택을 변경하면 현재 타이머를 멈추고 클릭 수와 구간 기록을 0으로 돌립니다. 새 모드의 READY 상태에서 다시 시작해야 합니다.

이미 저장된 다른 모드의 최고 기록은 유지됩니다. 모드 선택 자체도 브라우저 설정에 저장되므로 다음에 페이지를 열 때 해당 값을 다시 사용할 수 있습니다.

5초는 최고 속도보다 시작 방식의 차이가 크게 느껴질 수 있습니다

5초는 전체 시간이 짧아서 시작 직후의 작은 지연도 전체 결과에서 차지하는 비중이 큽니다. 시작 버튼을 누른 뒤 손을 패드로 옮기는 방식과 READY 패드 첫 입력으로 바로 시작하는 방식을 섞으면 체감 차이가 더 커질 수 있습니다.

기록을 비교할 목적이라면 한 가지 시작 방식으로 고정하세요. 같은 조건에서 여러 판을 비교해야 기록 상승이 실제 리듬 변화인지 판단하기 쉽습니다.

10초는 기본 CPS와 구간 안정성을 함께 보기 좋습니다

10초에서는 초반 버스트만으로 전체 결과를 끌어올리기 어렵고, 너무 느리게 시작하면 순간 속도를 충분히 활용하지 못합니다. 앞 5초와 뒤 5초의 페이스를 함께 보면서 후반 하락이 큰지 확인해 보세요.

최고 1초가 그대로인데 최종 CPS가 올라갔다면 순간 최고 속도보다는 여러 구간의 하락이 줄어든 결과일 수 있습니다.

20초는 초반 과속보다 유지 가능한 리듬이 중요합니다

20초는 세 모드 중 시간이 가장 길어 손가락 피로와 리듬 변화가 드러나기 쉽습니다. 처음 2~3초를 최고 버스트 속도로만 밀어붙이다가 후반 구간이 크게 떨어지면 전체 CPS가 낮아질 수 있습니다.

첫 몇 초를 조금 낮춰도 뒤쪽 10초 평균이 유지된다면 전체 클릭 수가 더 좋아질 수 있습니다. 한 번의 폭발적인 구간보다 끝까지 반복 가능한 속도를 찾는 데 적합한 모드입니다.

모바일은 패드 안에서 짧은 터치를 일정하게 반복합니다

모바일에서는 큰 패드를 터치하므로 화면 안에서 손가락을 이동할 필요가 없습니다. 한 손가락으로 기록을 비교할 때는 기기 방향과 잡는 자세를 비슷하게 유지하면 조건 차이를 줄일 수 있습니다.

스크롤하려다가 패드에 닿거나 손가락 위치를 계속 옮기면 리듬이 흔들릴 수 있습니다. 측정을 시작하기 전에 패드가 편하게 보이는 위치에 화면을 맞춘 뒤 진행하는 편이 좋습니다.

기록을 볼 때는 지속 속도와 순간 속도를 나눕니다

최종 CPS·총 클릭 수는 선택한 전체 시간 동안 얼마나 많은 입력을 유지했는지 보여 줍니다. 최고 1초는 그중 가장 빠른 한 구간의 순간 성능을 보여 줍니다.

최고 1초만 올라가고 최종 CPS가 내려갔다면 순간 버스트는 개선됐지만 다른 구간이 더 떨어졌을 수 있습니다. 반대로 최고 1초가 그대로인데 CPS가 올라가면 전체 페이스가 더 고르게 유지된 것으로 해석할 수 있습니다.

자주 생기는 기록 저하 패턴

  • 초반 과속: 첫 구간은 빠르지만 후반 평균이 크게 떨어집니다.
  • 시작 방식 혼합: READY 입력 시작과 시작 버튼 방식을 매번 바꿔 조건이 달라집니다.
  • 장치 혼합: 마우스·터치·Space 기록을 하나의 동일 조건처럼 비교합니다.
  • 최고 1초만 보기: 순간 기록은 좋아졌지만 전체 CPS 하락을 놓칩니다.
  • 탭 중단을 완료 판으로 착각: 도전 횟수는 올라가도 최고 기록에는 반영되지 않습니다.
  • 불편함을 참고 반복: 피로가 커지면 동작이 무너질 수 있으므로 통증·저림·불편함이 생기면 중단하는 편이 좋습니다.

초보 연습 순서

  1. 10초 기준판: 한 가지 입력 장치와 시작 방식을 정해 CPS·최고 1초를 확인합니다.
  2. 구간 확인: 뒤 5초 평균이 앞 5초보다 크게 떨어지는지 봅니다.
  3. 리듬 조정: 후반 급락이 크면 초반 속도를 조금 낮춰 전체 CPS 변화를 비교합니다.
  4. 5초 비교: 순간 버스트가 상대적으로 강한지 확인합니다.
  5. 20초 비교: 같은 자세와 입력 방식으로 지속 페이스를 확인합니다.

FAQ

READY 화면의 첫 클릭도 기록에 포함되나요?

아니요. 패드·터치·Space로 READY 상태에서 시작하면 첫 입력은 타이머 시작 신호로만 사용되고 클릭 수에는 포함되지 않습니다.

시작 버튼을 누른 뒤 첫 클릭은 포함되나요?

네. 시작 버튼이 이미 타이머를 시작했기 때문에 그다음 패드·터치·Space 입력부터 클릭 수가 증가합니다.

Space를 계속 누르고 있으면 자동 반복도 CPS에 들어가나요?

아니요. 현재 런타임은 반복 키 이벤트를 제외합니다. 사용자가 직접 반복해서 누른 Space 입력만 집계합니다.

5초 페이스는 앞 3초가 더 길어서 항상 유리한가요?

현재는 총 클릭 수가 아니라 각 구간의 평균을 비교합니다. 앞 3개 구간과 뒤 2개 구간의 초당 평균을 비교하므로 단순한 구간 수 차이를 보정합니다.

탭을 벗어난 판도 도전 횟수에는 포함되나요?

도전 횟수는 측정 시작 시 저장되므로 포함될 수 있습니다. 다만 중단된 판의 클릭 수·CPS·최고 1초는 최고 기록을 갱신하지 않습니다.

새로고침하면 진행 중인 클릭 수를 이어갈 수 있나요?

아니요. 진행 중 측정은 저장하지 않습니다. 완료된 장기 기록과 선택한 시간 모드는 같은 브라우저에 남습니다.

마우스와 Space 중 어느 기록이 더 정확한가요?

둘 다 게임에서 정상 입력으로 처리하지만 입력장치 특성이 다릅니다. 어느 한쪽을 절대 기준으로 보기보다 같은 장치·같은 시간 모드 기록끼리 비교하는 것이 좋습니다.
