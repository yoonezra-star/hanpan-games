두더지 찾기 공략: 콤보·입력 정확도·폭탄 피하기

두더지 찾기는 짧은 제한시간 동안 한 칸씩 나타나는 일반·골든 두더지를 잡고 폭탄을 피하는 반응 게임입니다. 최고 점수만 쫓기보다 아이콘을 구분한 뒤 한 번씩 정확히 입력하고, 놓침과 오클릭이 각각 어떤 기록에 영향을 주는지 이해하는 것이 중요합니다.

업데이트 2026년 8월 27일 · 한판게임 두더지 찾기 실제 런타임 기준

난이도별 보드·시간·노출 시간이 모두 다릅니다

쉬움3×3 · 35초 · 약 900ms
보통4×4 · 30초 · 약 700ms
어려움5×5 · 25초 · 약 520ms

어려움으로 갈수록 확인해야 할 칸은 9개에서 25개까지 늘고, 한 개체가 보이는 시간은 짧아집니다. 2026년 8월 27일 런타임에서는 시작 버튼도 선택한 난이도에 맞춰 35초·30초·25초를 정확히 표시하도록 수정했습니다.

한 번에 한 개체만 나타납니다

보드에는 동시에 여러 목표가 뜨지 않습니다. 현재 활성 칸 하나에 일반 두더지 🐹, 골든 ⭐, 폭탄 💣 가운데 하나가 나타나고, 처리되거나 노출 시간이 끝나면 다음 무작위 칸으로 넘어갑니다.

일반·골든 목표를 성공적으로 눌렀거나 폭탄을 잘못 눌렀을 때는 현재 개체를 즉시 제거하고 약 100ms 뒤 다음 개체를 생성합니다. 빈 칸 오입력은 현재 개체를 제거하지 않습니다.

생성 확률은 일반 76%·골든 14%·폭탄 10%입니다

매 등장마다 난수 하나로 종류를 정합니다. 폭탄은 약 10%, 골든은 약 14%, 나머지 약 76%가 일반 두더지입니다. 이 비율은 개별 등장 확률이므로 25~35초짜리 한 판에서 정확히 같은 비율로 나오는 것은 아닙니다.

폭탄은 ‘눌러야 할 목표’가 아니라 기다려야 할 대상입니다. 폭탄이 노출 시간을 다 채우고 사라져도 감점이나 콤보 초기화가 발생하지 않습니다.

일반과 골든 점수에는 콤보 보너스가 붙습니다

일반 또는 골든을 성공적으로 누르면 먼저 콤보가 1 증가합니다. 그 뒤 점수는 기본 점수 + min(20, 현재 콤보×2)로 계산됩니다.

  • 일반 두더지: 기본 10점 + 콤보 보너스
  • 골든 두더지: 기본 25점 + 콤보 보너스
  • 콤보 보너스: 현재 콤보×2, 최대 +20점

예를 들어 콤보 1에서 일반을 잡으면 12점, 콤보 5에서 일반을 잡으면 20점, 콤보 10 이상에서는 일반 한 번당 최대 30점을 받을 수 있습니다.

빈 칸 클릭과 폭탄 클릭은 손실이 다릅니다

현재 활성 칸이 아닌 다른 구멍을 누르면 전체 클릭 수가 1 증가하고 점수 2점을 잃으며 콤보가 0이 됩니다. 점수는 0 아래로 내려가지 않습니다.

폭탄을 누르면 전체 클릭 수가 1 증가하고 점수 15점을 잃으며 콤보가 0이 됩니다. 폭탄 손실이 빈 칸보다 크기 때문에 모든 변화에 반사적으로 손을 내기보다 아이콘 종류를 확인하는 것이 중요합니다.

빈 칸을 잘못 눌러도 현재 목표는 바로 사라지지 않습니다

오입력으로 빈 구멍을 눌렀을 때는 활성 두더지나 골든의 기존 노출 타이머가 그대로 진행됩니다. 시간이 남아 있다면 실제 활성 칸을 다시 눌러 성공할 수 있습니다.

따라서 빈 칸을 한 번 잘못 눌렀다고 주변을 연타할 필요가 없습니다. 연타할수록 전체 클릭 수가 늘고 입력 정확도가 더 떨어질 수 있으므로 실제 아이콘 위치를 다시 확인하세요.

놓침은 점수 감점 없이 콤보만 끊습니다

일반 또는 골든 두더지가 제한 노출 시간 안에 눌리지 않으면 현재 콤보가 0으로 초기화되고 다음 개체가 나타납니다. 놓침 자체에 -2점이나 -15점 같은 직접 감점은 없습니다.

반대로 폭탄은 놓치는 것이 올바른 플레이입니다. 폭탄이 자연스럽게 사라질 때는 콤보도 유지됩니다.

정확도는 ‘목표 포착률’이 아니라 ‘입력 정확도’입니다

화면의 정확도는 성공한 일반·골든 클릭 ÷ 전체 클릭 × 100을 정수 백분율로 반올림한 값입니다. 일반·골든 성공만 분자에 들어가고, 빈 칸과 폭탄 클릭은 분모에만 들어갑니다.

두더지를 놓쳐 아무것도 누르지 않은 경우에는 전체 클릭 수가 늘지 않기 때문에 정확도를 직접 낮추지 않습니다. 그래서 100% 정확도라고 해서 등장한 모든 두더지를 잡았다는 뜻은 아닙니다. 이 지표는 실제로 누른 입력이 얼마나 정확했는지를 보여 줍니다.

한 등장당 성공은 한 번만 인정됩니다

이전 런타임에서는 성공 입력 뒤 다음 개체가 생성되기 전 약 100ms 동안 같은 활성 칸이 남아 있어 빠르게 연속 클릭하면 하나의 두더지에서 점수·히트·콤보를 여러 번 얻을 가능성이 있었습니다.

2026년 8월 27일에는 성공 판정 즉시 현재 개체와 활성 슬롯을 제거하도록 수정했습니다. 이제 하나의 일반·골든 등장은 최대 한 번의 성공만 기록하므로 점수와 정확도 기록을 같은 기준으로 비교할 수 있습니다.

중앙 시야를 기준점으로 두면 탐색 거리가 줄어듭니다

3×3에서는 중앙 칸, 4×4와 5×5에서는 보드 중앙 부근을 시선 기준으로 두는 것이 좋습니다. 직전에 잡은 칸을 계속 바라보면 다음 개체가 반대편에 생겼을 때 발견이 늦어집니다.

성공 입력 직후 시선을 중앙 부근으로 되돌리고 주변의 아이콘 변화를 감지하세요. 모든 칸을 순서대로 훑기보다 변화가 생긴 위치를 찾는 방식이 보드가 커질수록 효율적입니다.

쉬움에서는 아이콘 구분과 정확도를 먼저 익힙니다

쉬움은 3×3, 35초, 약 900ms 노출이라 판단 여유가 가장 큽니다. 폭탄을 한 번도 누르지 않고 빈 칸 오입력을 줄이는 것을 첫 목표로 잡으세요.

높은 입력 정확도를 유지하면서 놓침이 줄어 최대 콤보가 길어지기 시작하면 보통 난이도로 넘어가기 좋습니다.

보통에서는 중앙 시야와 손 이동을 일정하게 유지합니다

보통은 4×4, 30초, 약 700ms입니다. 칸이 16개로 늘기 때문에 시선이 직전 위치에 남아 있으면 반대쪽 개체를 놓치기 쉽습니다.

최고 점수는 오르는데 입력 정확도가 크게 낮아진다면 속도를 지나치게 앞세우고 있을 수 있습니다. 한 판에서는 빈 칸·폭탄 클릭을 줄이는 목표, 다음 판에서는 놓침을 줄이는 목표처럼 원인을 나눠 연습하세요.

어려움에서는 520ms 안에 구분하는 연습이 핵심입니다

어려움은 5×5, 25초, 약 520ms라 탐색 범위가 넓고 판단 시간은 짧습니다. 모든 등장에 무조건 반응하기보다 ‘두더지는 누르고 폭탄은 기다린다’는 구분을 유지하는 것이 중요합니다.

한두 개 일반 목표를 놓치더라도 폭탄을 눌러 -15점과 콤보 손실을 만드는 것보다 다음 정상 목표부터 다시 흐름을 만드는 편이 안정적입니다.

모바일과 마우스 기록은 같은 조건끼리 비교합니다

모든 구멍은 실제 버튼이라 마우스 클릭과 터치 입력을 모두 사용할 수 있습니다. 모바일 5×5에서는 손가락이 인접 칸을 가릴 수 있으므로 입력 직후 손가락을 화면에서 조금 떼어 다음 개체를 확인하는 편이 좋습니다.

마우스와 터치는 이동 거리와 입력 지연 특성이 다르므로 최고 점수 변화를 볼 때는 같은 기기, 같은 입력 방식, 같은 난이도끼리 비교하세요.

도전 횟수는 시작 즉시 저장됩니다

시작 버튼을 누르면 해당 난이도의 attempts가 바로 1 증가합니다. 제한시간이 끝난 뒤 증가하는 완주 횟수 개념이 아닙니다.

따라서 시작 후 탭을 나가 중단한 판도 도전 횟수에는 남을 수 있습니다. 도전 횟수와 정상 완료 횟수를 같은 값으로 해석하지 않는 것이 좋습니다.

최고 기록은 정상 완료 판에서만 갱신됩니다

난이도별 최고 점수 bestScore, 최대 콤보 bestCombo, 최고 정확도 bestAccuracy는 제한시간이 0이 되어 정상 종료된 판에서만 갱신됩니다.

점수·콤보·정확도는 각각 별도의 최대값으로 저장되므로 세 기록이 반드시 같은 판에서 만들어진 값은 아닙니다.

탭을 벗어나면 현재 판을 중단합니다

2026년 8월 27일 런타임은 진행 중 브라우저 탭이 숨겨지면 제한시간 타이머와 개체 생성 타이머를 정리하고 현재 도전을 중단합니다. 돌아왔을 때 남은 시간부터 이어서 플레이하지 않습니다.

이는 백그라운드에서 브라우저가 타이머를 늦추는 상황이 기록 조건에 섞이지 않도록 하기 위한 처리입니다. 중단 판은 최고 기록을 갱신하지 않지만 시작 시 이미 증가한 도전 횟수는 남을 수 있습니다.

진행 중인 판은 저장하거나 복구하지 않습니다

현재 점수, 남은 시간, 활성 두더지, 콤보, 클릭 수는 localStorage에 진행 상태로 저장되지 않습니다. 새로고침하거나 탭 이탈로 중단한 뒤에는 새 판을 시작해야 합니다.

장기 기록과 마지막 선택 난이도만 브라우저에 남습니다.

브라우저에 저장되는 값

hanpan-mole-records-v2에는 쉬움·보통·어려움별 attempts, bestScore, bestCombo, bestAccuracy가 저장됩니다.

hanpan-mole-prefs-v2에는 마지막 선택 난이도 difficulty가 저장됩니다. 브라우저 데이터를 삭제하거나 다른 브라우저·기기로 이동하면 이 로컬 기록은 이어지지 않을 수 있습니다.

자주 나오는 실패 패턴

  • 직전 칸만 계속 봄: 다음 개체가 먼 곳에 나오면 발견이 늦습니다.
  • 모든 변화에 즉시 클릭: 폭탄 판별 전에 손이 나가 -15점과 콤보 손실이 생깁니다.
  • 빈 칸 오입력 뒤 연타: 현재 목표가 남아 있는데 추가 오입력만 늘 수 있습니다.
  • 100% 정확도를 포착률로 해석: 놓침은 정확도 분모에 들어가지 않으므로 별도입니다.
  • 점수만 비교: 최대 콤보와 입력 정확도를 같이 봐야 기록이 흔들린 원인을 찾기 쉽습니다.
  • 중단 판을 완료 기록으로 착각: 도전 횟수는 남을 수 있지만 최고 기록은 정상 종료 판만 반영합니다.

초보자용 연습 순서

  1. 쉬움에서 폭탄 클릭 0회를 먼저 목표로 합니다.
  2. 빈 칸 오입력을 줄여 입력 정확도를 안정시킵니다.
  3. 중앙 시야를 유지해 놓침을 줄이고 최대 콤보를 늘립니다.
  4. 같은 조건으로 보통에서 4×4 탐색에 적응합니다.
  5. 어려움에서는 무리한 연타보다 520ms 안의 아이콘 구분을 연습합니다.
  6. 같은 기기·같은 난이도에서 점수, 콤보, 입력 정확도를 함께 비교합니다.

FAQ

쉬움도 30초인가요?

아닙니다. 쉬움은 35초, 보통은 30초, 어려움은 25초입니다. 시작 버튼도 선택한 난이도의 시간을 표시합니다.

두더지를 놓치면 정확도도 내려가나요?

직접 내려가지 않습니다. 놓침은 클릭 수에 포함되지 않기 때문에 입력 정확도 분모가 늘지 않지만 현재 콤보는 0이 됩니다.

폭탄은 그냥 기다리면 되나요?

네. 폭탄을 누르지 않고 노출 시간이 지나게 두면 감점도 없고 콤보도 유지됩니다.

빈 칸을 잘못 누르면 현재 두더지는 사라지나요?

아닙니다. 기존 노출 시간이 남아 있다면 활성 칸을 다시 눌러 성공할 수 있습니다. 다만 빈 칸 클릭은 -2점, 콤보 초기화, 입력 정확도 하락을 만듭니다.

같은 두더지를 빠르게 여러 번 눌러 점수를 올릴 수 있나요?

아닙니다. 2026년 8월 27일 수정으로 성공 즉시 현재 개체를 제거해 한 등장당 성공은 한 번만 인정됩니다.

탭을 나갔다 돌아오면 이어서 할 수 있나요?

아닙니다. 현재 판은 중단되고 새 도전을 시작해야 합니다. 이미 시작 시 증가한 도전 횟수는 남을 수 있습니다.

기록은 난이도별로 따로 저장되나요?

네. 쉬움·보통·어려움 각각 도전 횟수, 최고 점수, 최대 콤보, 최고 정확도를 별도로 저장합니다.

직접 플레이하고 관련 가이드 보기

두더지 찾기 바로 플레이에서 쉬움부터 폭탄 클릭 없이 기준 기록을 만들어 보세요. 시각 탐색 중심 게임을 더 비교하려면 집중력·주의력 게임 추천, 반응 중심 게임은 반응속도 게임 추천, 간단한 입력 게임은 간단 조작 게임 추천도 참고할 수 있습니다.
