별자리 잇기 공략: 6단계·순서·저장·최단 시간

한판게임의 별자리 잇기는 무작위 위치에 놓인 숫자 별을 1번부터 순서대로 눌러 연결하는 시각 탐색 퍼즐입니다. 고정된 1분 제한은 없으며, 각 단계의 모든 별을 완성하는 데 걸린 시간과 실수 수를 기록합니다.

2026년 8월 27일 런타임 기준 핵심 규칙

현재 버전은 총 6단계이며 별 개수는 5개부터 10개까지 한 개씩 증가합니다. 한 단계를 완료하면 다음 단계가 해금되고, 이미 해금한 단계는 단계 선택 목록에서 바로 다시 고를 수 있습니다.

  • 1단계: 5개 별
  • 2단계: 6개 별
  • 3단계: 7개 별
  • 4단계: 8개 별
  • 5단계: 9개 별
  • 6단계: 10개 별

새 별자리를 시작할 때 각 별의 위치가 무작위로 생성됩니다. 별은 보드 가장자리에서 약간 떨어진 범위에 배치되고, 서로 지나치게 가까운 위치를 피하도록 여러 번 위치를 다시 뽑습니다.

이 게임에는 1분 같은 고정 제한시간이 없습니다

시간은 새 별자리를 시작한 순간부터 해당 단계의 마지막 별을 맞힐 때까지 누적됩니다. 제한시간 안에 실패하는 구조가 아니므로 느리더라도 단계 자체는 계속 진행할 수 있습니다.

완료 기록은 정수 초 단위로 저장합니다. 내부 계산에서는 누적 밀리초를 초로 내림하고, 매우 빠른 완료라도 최소 1초로 기록합니다. 따라서 같은 단계에서 세밀한 밀리초 경쟁보다는 초 단위 기록과 실수 수를 함께 보는 편이 적절합니다.

현재 눌러야 할 별은 시각적으로 강조됩니다

HUD에는 ‘다음 별’ 번호가 표시되고, 보드에서도 현재 정답 별에 강조 효과가 적용됩니다. 숫자를 읽는 것과 함께 이 표시를 활용하면 다음 목표를 빠르게 찾을 수 있습니다.

다만 강조만 따라 급하게 누르기보다, 현재 별을 누르기 직전에 다음 1~2개 숫자의 대략적인 방향까지 확인해 두면 연속 입력 사이의 탐색 시간을 줄이기 쉽습니다.

연결선은 이미 성공한 별끼리만 표시됩니다

현재 런타임에서는 아직 누르지 않은 다음 별까지 선이 미리 그려지지 않습니다. 예를 들어 1번만 성공한 상태에서는 1→2 선이 나타나지 않고, 2번까지 성공한 뒤에 1→2 연결선이 표시됩니다.

이전 버전에서는 연결선이 한 단계 앞서 표시돼 다음 목표를 미리 가리키는 문제가 있었지만, 현재는 완료한 연결만 보이도록 교정했습니다. 연결선은 ‘지나온 경로’를 확인하는 표시로 이해하면 됩니다.

잘못된 번호를 눌러도 진행 상태는 초기화되지 않습니다

현재 필요한 번호가 아닌 별을 누르면 실수가 1회 증가합니다. 이미 성공한 별과 연결선, 다음 번호는 그대로 유지됩니다. 예를 들어 4번까지 성공한 상태에서 7번을 잘못 눌렀다면 다시 1번부터 시작하지 않고 5번을 찾으면 됩니다.

오답 뒤 연속으로 아무 별이나 누르면 실수만 더 늘어날 수 있습니다. HUD의 다음 별 번호와 강조 표시를 다시 확인한 뒤 한 번 정확하게 입력하는 편이 좋습니다.

‘한 단계 되돌리기’도 실수 1회로 계산됩니다

되돌리기 버튼은 오답 횟수를 지우는 기능이 아닙니다. 마지막으로 성공한 별 하나를 취소해 다음 번호를 한 단계 이전으로 돌리고, 동시에 실수를 1회 추가합니다.

따라서 최소 실수 기록을 노리는 판에서는 되돌리기가 이득이 아닙니다. 특정 연결을 다시 확인하거나 연습 흐름을 되짚고 싶을 때 사용하는 보조 기능으로 보는 것이 정확합니다.

‘새 별자리’는 현재 판을 새 배치로 교체합니다

진행 중 새 별자리를 누르면 같은 단계에서 별 위치를 다시 생성하고, 다음 번호는 1, 실수와 경과 시간은 0으로 초기화됩니다. 기존 진행을 별도의 실패 기록으로 남기지는 않습니다.

최단 기록을 노리다 초반 흐름이 크게 꼬였다고 새 별자리를 반복하면 완료 횟수에는 반영되지 않습니다. 기록 비교를 공정하게 하고 싶다면 같은 기준으로 완주한 판을 중심으로 비교하세요.

해금된 단계는 직접 선택할 수 있습니다

처음에는 1단계만 선택할 수 있습니다. 1단계를 완료하면 2단계가 해금되고 같은 방식으로 최대 6단계까지 열립니다. 현재 버전에서는 해금된 단계가 단계 선택 목록에 유지되므로 페이지를 다시 방문한 뒤에도 앞단계를 다시 모두 클리어할 필요가 없습니다.

진행 중인 판에서는 단계 선택을 비활성화해 실수로 현재 저장 상태를 바꾸는 일을 막습니다. 완료하거나 아직 시작하지 않은 상태에서 원하는 해금 단계를 고른 뒤 새 별자리를 시작하면 됩니다.

최단 시간과 최소 실수는 단계별로 따로 저장됩니다

각 단계에는 최단 완료 시간과 최소 실수가 별도의 최고 기록으로 남습니다. 가장 빠른 판과 가장 정확한 판이 같은 판일 필요는 없습니다.

처음에는 실수 0회에 가까운 안정적인 플레이를 만들고, 순서 탐색이 익숙해진 뒤 클릭 사이의 멈춤을 줄이는 방식이 좋습니다. 정확성과 속도를 한 판에서 동시에 무리하게 올리면 오답 때문에 오히려 두 기록이 모두 나빠질 수 있습니다.

전체 완료 횟수와 최고 해금 단계도 저장됩니다

장기 기록에는 단계별 최고 기록 외에 전체 완료 횟수와 현재까지 해금된 최고 단계가 포함됩니다. 전체 완료 횟수는 어느 단계든 정상적으로 마지막 별까지 성공했을 때 1 증가합니다.

별도의 ‘도전 횟수’ 필드는 없습니다. 새 별자리를 시작했다가 중간에 교체하거나 페이지를 떠난 횟수를 장기 기록으로 세지 않는 구조입니다.

진행 중 상태는 별도 저장 키에 보관됩니다

진행 저장에는 현재 단계, 생성된 별 좌표, 다음 번호, 실수 수와 누적 경과 시간이 들어갑니다. 새로고침 후 유효한 저장 데이터가 있으면 같은 배치와 진행 상태를 복구합니다.

사용되는 브라우저 저장 키는 다음과 같습니다.

  • 진행 저장: hanpan-constellation-save-v2
  • 장기 기록: hanpan-constellation-records-v2

진행 저장에는 version, stage, points, next, mistakes, elapsed가 들어갑니다. 장기 기록에는 unlocked, clears, bestTime, bestMistakes가 사용됩니다.

단계를 완료하면 진행 저장은 제거되고 최고 기록만 남습니다

마지막 별을 성공하면 현재 진행 저장은 삭제됩니다. 그 뒤 완료 횟수, 단계별 최단 시간, 단계별 최소 실수와 다음 단계 해금 상태가 장기 기록에 반영됩니다.

즉 완료한 판을 새로고침한다고 마지막 순간의 별 배치를 복구하는 것은 아닙니다. 완료 결과만 장기 기록으로 남고, 다음 플레이는 새 배치로 시작합니다.

탭을 벗어난 동안에는 시간이 증가하지 않습니다

진행 중 브라우저 탭이 숨겨지면 타이머를 멈추고 그 시점까지의 경과 시간을 저장합니다. 다시 탭으로 돌아오면 저장된 시간부터 측정을 재개합니다.

따라서 다른 탭을 오래 보고 돌아왔다고 그 시간이 최단 완료 기록에 그대로 더해지지는 않습니다. 다만 시선 흐름과 숫자 위치 기억이 끊길 수 있으므로 순수한 기록 도전은 한 번에 이어서 하는 편이 비교하기 쉽습니다.

페이지 새로고침과 새 별자리는 서로 다릅니다

새로고침은 유효한 진행 저장이 있으면 현재 배치를 복원합니다. 반대로 ‘새 별자리’ 버튼은 같은 단계의 새 좌표를 만들고 기존 진행을 대체합니다.

중간에 잠시 브라우저를 닫았다가 같은 판을 이어 가려는 경우에는 새 별자리를 누르지 말고 복구된 상태를 그대로 사용하세요.

초반에는 현재 번호보다 다음 방향을 미리 읽습니다

1~2단계는 별이 5~6개라 전체 배치를 한눈에 보기 쉽습니다. 현재 별을 누르기 전에 다음 별 하나 또는 둘의 방향을 미리 확인하는 습관을 만들기 좋은 구간입니다.

현재 번호 확인 → 다음 방향 확인 → 현재 별 클릭 → 즉시 다음 별로 시선 이동 순서를 반복하면 클릭 사이에 매번 보드를 처음부터 다시 검색하는 시간을 줄일 수 있습니다.

후반 단계에서는 보드를 큰 구역으로 나눠 봅니다

5~6단계의 9~10개 별을 모두 정확한 좌표로 외우려 하면 부담이 큽니다. 다음 별을 ‘왼쪽 위’, ‘가운데 아래’, ‘오른쪽’처럼 큰 구역으로 먼저 기억한 뒤 클릭 직전에 숫자를 확인하는 방식이 실용적입니다.

무작위 배치는 판마다 달라지므로 특정 좌표를 암기하기보다 방향과 구역을 읽는 습관을 익히는 것이 반복 플레이에 더 잘 적용됩니다.

최단 시간 도전과 최소 실수 도전을 분리합니다

최단 시간 도전에서는 이미 안정된 순서 읽기를 바탕으로 클릭 사이 멈춤을 줄이는 데 집중하세요. 최소 실수 도전에서는 숫자가 몰린 구간에서 조금 느려져도 정확한 번호를 확인하는 것이 우선입니다.

두 기록이 별도로 저장되므로 한 판에서 무리하게 둘을 동시에 갱신할 필요가 없습니다. 같은 단계와 같은 기기에서 목적을 나눠 도전하면 변화 원인을 더 쉽게 파악할 수 있습니다.

마우스와 터치는 같은 조건끼리 비교합니다

별은 일반 버튼으로 동작하므로 마우스 클릭과 화면 터치를 모두 사용할 수 있습니다. 모바일에서는 별 크기가 약간 작아지고 보드 높이도 조정됩니다.

마우스와 터치는 이동 방식과 화면 크기가 다르므로 최단 시간 기록을 비교할 때는 가능한 한 같은 기기와 같은 입력 방식을 유지하세요. 전용 전역 키보드 단축키는 없지만 포커스된 버튼은 브라우저의 기본 버튼 키보드 동작을 따릅니다.

자주 나오는 실패 패턴

  • 현재 번호만 보고 매번 멈춤: 다음 별을 찾는 탐색 시간이 반복됩니다.
  • 숫자가 몰린 곳에서 손부터 움직임: 짧은 이동 구간에서 오답이 늘기 쉽습니다.
  • 오답 뒤 처음부터 다시 탐색: 진행은 유지되므로 HUD의 다음 번호부터 계속하면 됩니다.
  • 되돌리기를 실수 삭제로 오해: 되돌리기 자체가 실수 1회입니다.
  • 연결선을 다음 정답 힌트로 기대: 현재 버전의 선은 이미 성공한 연결만 나타냅니다.
  • 해금 단계를 다시 처음부터 플레이: 완료했던 단계는 선택 목록에서 직접 고를 수 있습니다.

초보자용 6단계 연습 순서

  1. 1단계에서 실수 0회를 먼저 목표로 합니다.
  2. 현재 별을 누르기 전에 다음 별 하나의 방향을 미리 확인합니다.
  3. 연결선으로 이미 처리한 경로와 남은 번호를 구분합니다.
  4. 2~4단계에서 같은 루틴을 유지하며 클릭 사이의 멈춤을 줄입니다.
  5. 5~6단계에서는 보드를 큰 구역으로 나눠 다음 번호의 방향을 기억합니다.
  6. 해금된 단계를 다시 선택해 최소 실수와 최단 시간을 각각 갱신합니다.

FAQ

별자리 잇기는 몇 단계인가요?

총 6단계입니다. 1단계 5개 별에서 시작해 단계마다 하나씩 늘어나 6단계에서는 10개 별을 연결합니다.

1분 안에 끝내야 하나요?

아닙니다. 고정 제한시간은 없습니다. 해당 단계의 모든 별을 순서대로 성공하면 종료됩니다.

연결선이 다음 정답을 가리키나요?

현재 버전에서는 아닙니다. 연결선은 이미 성공한 별 사이에만 표시되고, 현재 정답은 숫자와 강조 표시로 확인합니다.

잘못 누르면 처음부터 다시 해야 하나요?

아닙니다. 실수 1회만 추가되고 기존 진행은 유지됩니다. HUD에 표시된 다음 번호부터 계속하면 됩니다.

되돌리기를 쓰면 실수가 없어지나요?

아닙니다. 마지막 성공 연결을 하나 취소하며 되돌리기 자체가 실수 1회로 추가됩니다.

새로고침하면 현재 판이 사라지나요?

진행 중 저장이 유효하면 단계, 별 위치, 다음 번호, 실수와 경과 시간을 복구합니다. 완료한 판은 진행 저장 대신 최고 기록만 남습니다.

다른 탭을 보는 동안에도 시간이 계속 올라가나요?

아닙니다. 탭이 숨겨진 동안에는 타이머가 일시정지되고 돌아오면 이어서 측정합니다.

해금한 5단계를 다시 하려면 1단계부터 깨야 하나요?

아닙니다. 현재 버전은 해금된 단계를 선택 목록에서 직접 고를 수 있습니다. 진행 중일 때만 단계 선택이 잠깁니다.

어떤 기록이 저장되나요?

최고 해금 단계, 전체 완료 횟수, 단계별 최단 시간과 최소 실수가 브라우저에 저장됩니다. 진행 중에는 별 배치와 현재 상태가 별도 저장됩니다.
