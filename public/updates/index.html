업데이트 노트

한판게임의 주요 변경 내역을 정리합니다. 새 게임, 플레이 개선, 정책 페이지 보강, 도움말 업데이트처럼 사용자가 확인하면 좋은 내용을 날짜별로 남깁니다.

2026년 8월 16일

프리셀 클래식 정식 추가

프리셀 클래식을 45번째 게임으로 추가했습니다. 8개 열, 4개 임시칸, 4개 기초칸과 실제 묶음 이동 한도를 적용했으며 터치·드래그 이동, 힌트, 50회 되돌리기, 안전 자동 정리, 자동 저장과 이어하기, 연승과 최고 완주 기록을 지원합니다.

미로 추격과 카드 게임 대표 콘텐츠 보강

랜덤 미로와 세 종류의 추격 AI를 갖춘 미로 추격 클래식을 공개하고, 프리셀과 카드 솔리테어의 규칙, 조작, 점수 기준, 초보 공략, 심화 전략, 모바일 팁과 FAQ를 확장했습니다. 메인 대표 게임과 전체 게임 목록, 사이트맵도 45개 게임 기준으로 갱신했습니다.

2026년 8월 15일

게임 선택기 이동 방식 개선

게임 상세 페이지의 선택 목록에서 다른 게임을 고르면 해당 게임의 플레이 영역으로 즉시 이동하도록 수정했습니다. 옆의 시작 버튼도 선택된 게임 주소를 직접 확인해 같은 위치로 이동합니다.

전체 게임 미리보기 이미지 적용

게임 목록에서 규칙과 화면 구성을 더 빠르게 비교할 수 있도록 40개 게임 모두에 16:9 미리보기 이미지를 적용했습니다. 새 이미지는 실제 플레이 화면을 사용하며 모바일에서도 목록을 가볍게 열 수 있도록 WebP 형식으로 최적화했습니다.

40개 게임 실행 안정성 점검

전체 게임의 시작, 조작, 종료 흐름을 다시 점검했습니다. 클릭 스프린트, 두더지 찾기, 비행기 피하기, 디저트 받기, 정원 물주기는 시작 버튼을 누른 뒤에만 시간이 흐르며 게임이 끝난 뒤에는 입력이 잠깁니다. 숫자 금고의 입력 범위와 시각 안내도 같은 기준으로 맞췄습니다.

퍼즐 공정성과 모바일 조작 개선

슬라이딩 퍼즐은 항상 풀 수 있는 배치로 시작하고, 매치 3은 가능한 수가 없는 보드를 자동으로 다시 섞습니다. 블록 채우기와 패턴 기억은 미리 보기와 재시작 상태를 정리했습니다. 비행기 피하기와 디저트 받기에는 반응할 시간을 확보한 판정 방식, 키보드 조작, 모바일 속도 선택을 적용했습니다.

2026년 8월 14일

한국 전통놀이 4종과 카테고리 개편

제기차기, 투호, 딱지치기, 공기놀이를 움직임·점수·효과음·최고 기록을 갖춘 게임으로 추가했습니다. 전체 게임 목록은 한국 전통놀이, 고전 오락실, 퍼즐, 보드·전략, 두뇌·기억, 순발력·기록의 여섯 종류로 다시 정리하고 네 게임의 고유 대표 이미지를 제작했습니다. 사이트 방향과 맞지 않는 이전 게임 세 개는 카탈로그와 공개 페이지에서 제거했습니다.

모바일 가로·전체화면 플레이

모든 게임 실행 영역에 전체화면 전환을 추가하고 모바일 가로 화면에 맞춘 플레이 레이아웃을 적용했습니다. 전체화면에서는 점수를 작은 HUD로 표시하고 게임판을 남은 영역까지 확대하며, 조작 버튼은 화면 하단에 모아 배치합니다. 전체화면 API가 제한된 브라우저에서도 게임 영역을 화면에 채우는 대체 모드로 플레이할 수 있습니다.

플레이 점수 HUD 적용

점수, 목숨, 단계, 최고 기록을 게임판 바로 위의 기록 HUD로 통합했습니다. 모바일에서도 게임 화면을 가리지 않으며, 항목이 많은 게임은 자동으로 줄을 바꿔 표시합니다.

모바일 게임 속도 보정

고주사율 모바일 화면에서 일부 액션 게임이 더 빠르게 움직일 수 있던 프레임 의존 계산을 실제 경과 시간 기준으로 수정했습니다. 벽돌깨기, 퐁 랠리, 우주 방어선, 플래피 점프, 의자 질주에는 느림·보통·빠름 속도 선택을 추가했습니다.

대표 고전 아케이드 3종 심화

퐁 랠리에 7점제와 3단계 AI, 서브 카운트다운을 추가하고, 우주 방어선에는 적탄·보호막·연속 격추 배수를 적용했습니다. 뱀의 정원은 종료 후 재도전 흐름을 고치고 단계별 장애물과 별 보너스 먹이를 더했습니다. 세 게임 모두 키보드·터치 조작과 효과음 켜기·끄기를 지원합니다.

게임 선택과 플레이 우선 구조 적용

게임 상세 페이지 상단에 공개 게임 선택기와 바로 시작 버튼을 배치했습니다. 실제 게임판을 제목 바로 아래로 올리고 조작법, 공략, FAQ와 관련 콘텐츠는 플레이 영역 아래에서 읽을 수 있도록 순서를 정리했습니다.

블록 드롭 클래식 대표 퍼즐 확장

블록 드롭 클래식에 7-백 랜덤, 다음 블록, 홀드, 고스트 블록, 하드 드롭, 연속 줄 삭제 콤보를 추가했습니다. 이동·회전·고정·줄 삭제 효과음과 소리 토글, 키보드·터치 조작을 함께 적용했습니다.

벽돌깨기 미니 대표 아케이드 확장

벽돌깨기 미니에 세 가지 스테이지 패턴, 내구도 벽돌, 연속 명중 콤보, 와이드 패들, 멀티볼, 바닥 보호막을 추가했습니다. 키보드·포인터·터치 조작과 소리 설정, 로컬 최고 기록도 함께 정리해 짧은 한 판 안에서도 반복 플레이 흐름이 이어지도록 개선했습니다.

벽돌깨기 공략 최신화

벽돌깨기 초보 공략에 아이템을 받는 우선순위, 멀티볼 시선 처리, 콤보를 무리 없이 이어 가는 기준을 추가했습니다. 실제 게임 규칙과 공략 내용이 같은 흐름으로 이어지도록 보강했습니다.

2026년 7월 22일

게임 상세 페이지와 공략 연결 강화

각 게임 상세 페이지에 관련 공략 섹션을 추가했습니다. 게임을 플레이한 뒤 2048, 스네이크, 지뢰찾기, 기억력, 모바일 조작 같은 가이드로 자연스럽게 이어질 수 있도록 내부 링크를 보강했습니다.

가이드 구조화 데이터 보강

가이드 글 10편에 BreadcrumbList 구조화 데이터를 추가하고 발행 및 수정일을 화면에 표시했습니다. 검색엔진과 사용자가 글의 위치, 최신성, 관련 페이지 흐름을 더 분명하게 확인할 수 있도록 정리했습니다.

추가 공략 글 5편 발행

2048 초보 전략, 스네이크 오래 버티는 법, 지뢰찾기 기본 규칙, 기억력 게임 팁, 무료 브라우저 게임의 장점과 주의할 점을 새로 발행했습니다. 각 글은 관련 게임 페이지와 연결해 설명을 읽은 뒤 바로 플레이할 수 있도록 구성했습니다.

게임 목록 큐레이션 보강

전체 게임 페이지에 처음 방문, 모바일 추천, 차분한 퍼즐, 고전 아케이드 추천 묶음을 추가했습니다. 36개 게임을 단순 목록으로만 보여주지 않고 사용 상황에 맞게 고를 수 있도록 개선했습니다.

광고와 개인정보 안내 정합성 수정

개인정보처리방침, 도움말, 이용약관의 광고 관련 문구를 현재 Google 광고 서비스 스크립트 적용 상태에 맞게 수정했습니다. 광고는 게임 조작 버튼, 입력창, 결과 확인 영역과 혼동되지 않도록 관리한다는 기준도 함께 명확히 했습니다.

플레이 가이드 5편 발행

게임을 처음 고르는 사용자와 모바일 방문자가 더 쉽게 시작할 수 있도록 새 가이드 글을 발행했습니다. 짧은 휴식 게임 선택법, 벽돌깨기 공략, 블록 드롭 초보 배치법, 틱택토 전략, 모바일 브라우저 조작 팁을 각각 독립 페이지로 정리했습니다.

가이드 허브 개편

가이드 페이지를 단일 안내문에서 글 목록과 기본 플레이 원칙을 함께 제공하는 허브 구조로 바꿨습니다. 각 글에는 관련 게임 링크를 배치해 설명을 읽은 뒤 바로 플레이로 이어질 수 있도록 했습니다.

사이트맵 갱신

가이드 글 10개를 sitemap.xml에 추가하고, 홈과 가이드, 업데이트 페이지의 수정일을 2026년 7월 22일로 반영했습니다. 검색엔진이 새 콘텐츠를 더 쉽게 발견할 수 있도록 내부 링크도 홈과 가이드 허브에 보강했습니다.

2026년 7월 20일

공식 도메인 정합성 정리

사이트 기준 주소를 hanpangames.kr로 정리했습니다. robots.txt, sitemap.xml, canonical URL, 구조화 데이터의 대표 주소를 같은 도메인으로 맞춰 검색 엔진이 공식 주소를 더 분명하게 인식할 수 있도록 했습니다.

운영 신뢰 페이지 보강

소개, 문의, 개인정보처리방침, 이용약관, 도움말, 가이드 페이지에 운영 정보, 무료 이용 범위, 기록 저장 방식, 오류 제보 기준, 광고와 게임 화면 배치 원칙을 추가했습니다. 사용자가 사이트 성격과 문의 방법을 더 쉽게 확인할 수 있게 정리했습니다.

게임 화면 라이브 모션 보강

비캔버스 게임에도 움직이는 라이브 모션 레이어를 추가했습니다. 숫자 금고는 범위 미터, 사이먼 게임은 버튼 점멸 순서 기억 방식으로 보강하고 각 게임의 상태 변화가 더 분명하게 보이도록 했습니다.

개별 게임 페이지 확장

전체 공개 게임에 각각 독립된 게임 페이지를 추가했습니다. 각 페이지에는 바로 플레이 영역, 게임 방법, 공략 팁, 자주 묻는 질문, 관련 게임 링크를 함께 배치했습니다.

향수, 타이핑, 의자 레이스형 게임 보강

향수 소트 공방은 병을 옮겨 같은 향을 모으는 소트 퍼즐로, 타이핑 노선은 역 이름을 입력하는 레이스로 보강했습니다. 의자 질주는 새로 추가해 관성 있는 사무실 레이싱 게임으로 플레이할 수 있습니다.

고전형 아케이드 게임 추가

블록 드롭 클래식, 퐁 랠리, 우주 방어선, 플래피 점프를 추가했습니다. 네 게임 모두 캔버스 기반으로 구현해 키보드와 화면 버튼으로 바로 조작할 수 있습니다.

대표 게임 품질 보강

벽돌깨기 미니, 2048 한판, 스네이크, 지뢰찾기 미니, 스도쿠 미니, 매치3 퍼즐의 규칙과 화면 피드백을 보강했습니다. 키보드 조작, 최고 기록, 승패 판정, 연쇄 처리, 힌트, 깃발 모드처럼 반복 플레이에 필요한 기본 요소를 추가했습니다.

도움말과 운영 안내 보강

게임 기록 저장 방식, 모바일 플레이, 오류 제보 방법, 개인정보와 쿠키 관련 질문을 한 곳에서 볼 수 있도록 도움말를 추가했습니다. 처음 방문한 사용자가 게임 이용 전에 궁금한 내용을 빠르게 확인할 수 있습니다.

게임별 상세 페이지 추가

반응속도 체크, 숫자 금고, 기억 타일에 각각 상세 페이지를 추가했습니다. 각 페이지에는 플레이 방법, 기록 해석, 초보자 팁, 모바일 플레이 안내를 담았습니다.

필수 안내 페이지 정비

소개, 개인정보처리방침, 이용약관, 문의 페이지를 보강했습니다. 사이트 목적, 기록 저장 방식, 콘텐츠 권리, 문의 기준을 더 분명하게 정리했습니다.

핵심 게임 개선

다음 개선 예정
